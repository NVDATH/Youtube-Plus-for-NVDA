# YoutubePlus для NVDA

> YoutubePlus — это дополнение для людей, которые любят использовать YouTube, но находят многие функции на сайте труднодоступными — например, чтение комментариев к видео.
> Мы предоставляем эти функции через интерфейс NVDA в удобной для навигации форме, поддерживающей сочетания клавиш и полностью настраиваемой — без необходимости иметь дело с ключами API или подключать какие-либо личные аккаунты к дополнению.
> Вы можете отслеживать любимые каналы и быть уверенными, что увидите все видео с этих каналов, без того чтобы алгоритм YouTube их фильтровал.
> Мы также предоставляем систему избранного для видео, каналов, плейлистов и список для просмотра, чтобы сохранять контент, который вас заинтересовал, но на который у вас ещё не было времени посмотреть.
> Встроен поиск видео, который отображает результаты в том же интерфейсе, который используется во всём дополнении — а не просто в поле поиска, открывающем YouTube в браузере.
> Включена функция загрузки для сохранения видео или аудиофайлов, хотя она предоставлена как дополнительное удобство, а не как основная функция. Если загрузка — ваша главная потребность, существуют другие дополнения, посвящённые именно этой функции, которые вы, возможно, захотите изучить.
> Единственное, что это дополнение не делает — не встраивает видеоплеер. Мы считаем, что веб-плеер YouTube и так достаточно доступен. Если вы считаете, что его возможностей всё ещё не хватает, вы можете использовать другие дополнения, например [browserNav](https://addonstore.nvaccess.org/?channel=stable&language=en&apiVersion=2025.3.2&addonId=browsernav), чтобы улучшить взаимодействие.

## Сочетания клавиш и команды

В этом дополнении используется слоёвая система сочетаний клавиш для предотвращения конфликтов с другими дополнениями или командами NVDA.
Нажмите **NVDA+Y**, чтобы войти в режим команд YoutubePlus, затем нажмите одну из следующих клавиш для доступа к каждой функции или окну.

**Примечание:** Если основное сочетание клавиш (`NVDA+Y`) конфликтует с другим дополнением, вы можете изменить его через `NVDA -> Параметры -> Жесты ввода...` в категории «YoutubePlus».

### Клавиши, доступные в слое YoutubePlus

* a: (добавить в...) — Открывает подменю, позволяющее выбрать, куда добавить текущее видео или канал
* f: (открыть избранные видео) — Открывает окно избранных видео
* c: (открыть избранные каналы) — Открывает окно избранных каналов
* p: (открыть избранные плейлисты) — Открывает окно избранных плейлистов
* w: (показать список для просмотра) — Открывает окно списка для просмотра
* d: (загрузить) — Предлагает подтвердить, загружать видео или только аудио
* e: (поиск) — Открывает окно поиска видео
* q: (быстрый поиск) — Выполняет поиск на YouTube немедленно, используя выделенный текст или содержимое буфера обмена, если ничего не выделено — без предварительного открытия диалога поиска
* control+h: (история поиска) — Открывает окно «Избранное» непосредственно на вкладке «История поиска»
* i: (информация) — Открывает окно сведений о видео
* t: (показать временные метки) — Отображает временные метки или главы, если они доступны
* g: (получить описание миниатюры) — Загружает миниатюру видео и отправляет её в приложение Be My Eyes для живого описания
* m: (открыть управление подписками) — Открывает окно управления подписками
* s: (открыть ленту подписок) — Показывает видео с каналов, на которые вы подписаны
* u: (открыть управление профилями пользователей) — Открывает окно управления профилями пользователей
* l: (показать комментарии) — Отображает комментарии (подробности объясняются ниже)
* shift+l: (остановить мониторинг живого чата) — Останавливает мониторинг живого чата
* r: (переключить автоматическое чтение живого чата) — Переключает автоматическое озвучивание входящих сообщений живого чата
* v: (показать живой чат) — Повторно открывает окно живого чата, если вы закрыли его, пока трансляция ещё активна
* y: (открыть диалог настроек YoutubePlus) — Быстро открывает настройки NVDA и фокусируется на категории YoutubePlus.
* h: (справка) — Открывает окно со списком всех доступных сочетаний клавиш

**Примечание:** Для команд, которые действуют непосредственно на видео, дополнение сначала проверяет открытое окно браузера. Если активна страница с видео на YouTube, используется URL этого видео. Если страница с видео не открыта, проверяется буфер обмена на наличие URL YouTube.

## Подробности функций и команды

### a: (добавить в...)

Эта команда в слое YoutubePlus отправляет информацию о видео или канале в выбранное место назначения:

* Добавить в избранные видео (v)
* Добавить в избранные каналы (c)
* Добавить в избранные плейлисты (p)
* Подписаться на канал (s)
* Добавить в список для просмотра (w)

Дополнение сначала проверяет текущую открытую страницу браузера. Если это страница видео YouTube, оно извлекает URL и обрабатывает его в соответствии с вашим выбором. Если страница не является видео YouTube или браузер не открыт, проверяется буфер обмена на наличие URL YouTube.

Большинство команд работают с любым типом URL YouTube, поскольку дополнение может получить необходимую информацию. Например, если вы находитесь на странице видео и выбираете «Добавить в избранные каналы», дополнение может автоматически извлечь URL канала. То же самое относится и к подписке на канал.

Единственное исключение — плейлисты: у вас должна быть открыта страница плейлиста YouTube или в буфере обмена должен быть действительный URL плейлиста YouTube.

### d: (загрузить видео/аудио)

Эта команда открывает небольшой диалог с вопросом, хотите ли вы загрузить видео или только аудио. Вы можете установить папку назначения загрузки и настроить качество/формат в разделе [Настройки](#settings).

**Для загрузки видео требуется FFmpeg.** YouTube больше не предоставляет большинство видео в виде одного объединённого видео+аудиофайла, поэтому для объединения отдельных потоков необходим FFmpeg. YoutubePlus не включает FFmpeg в свой состав (чтобы не раздувать конфигурацию NVDA каждого пользователя его копией) — если FFmpeg не найден в вашей системе при загрузке видео и доступен инструмент Windows `winget`, YoutubePlus предложит установить его автоматически с помощью одного запроса «Да/Нет»; после установки загрузка продолжится автоматически без необходимости перезапуска NVDA. Если ни FFmpeg, ни `winget` недоступны, вы получите соответствующее уведомление, и загрузка будет чисто отменена.

Для загрузки только аудио FFmpeg по умолчанию не требуется. Он нужен только в том случае, если вы выбрали формат аудио, отличный от «Наилучший доступный (без преобразования)» в расширенных настройках формата ниже, поскольку преобразование в другой аудиоформат также выполняется через FFmpeg.

Обратите внимание, что функция загрузки предоставляется для удобства и может иметь ограничения при интенсивном использовании. Если вам нужно загружать большие объёмы контента с YouTube, рекомендуются другие специализированные инструменты.

### e: (поиск)

Эта команда открывает окно поиска YouTube. Введите запрос в поле поиска и нажмите Enter, чтобы выполнить поиск немедленно. Вы также можете переключиться на настройку количества отображаемых результатов — дополнение запоминает это значение для будущих поисков.

Поле поиска является полем со списком, которое запоминает ваши предыдущие поисковые запросы: нажмите стрелку вниз (или Alt+Вниз), чтобы раскрыть список предыдущих ключевых слов и выбрать одно из них вместо повторного ввода.

Результаты отображаются в том же формате [списка видео](#video-list), который используется во всём дополнении, а не как веб-страница YouTube. Вы можете получить доступ ко всем сведениям о видео так же, как и в любом другом списке видео в дополнении.

#### q: (быстрый поиск)

Более быстрая альтернатива диалогу поиска выше. Выделите текст в любом приложении (или скопируйте запрос в буфер обмена, если ничего не выделено), затем нажмите Q в слое YoutubePlus. Дополнение немедленно выполняет поиск на YouTube, используя этот текст и сохранённое количество результатов из вашего последнего поиска — без диалогов и дополнительных нажатий клавиш.

#### История поиска

Каждый выполненный вами поиск — как из диалога поиска, так и через быстрый поиск — автоматически сохраняется. Нажмите **Control+H** в слое YoutubePlus, чтобы перейти непосредственно на вкладку «История поиска» в окне «Избранное», где вы можете:

* Нажать Enter или кнопку **Искать снова**, чтобы повторно выполнить прошлый поиск
* Нажать **Новый поиск (Alt+N)**, чтобы открыть диалог поиска
* Нажать Delete или кнопку **Удалить**, чтобы удалить одну запись
* Нажать кнопку **Очистить всё**, чтобы очистить всю историю

### i: (информация о видео)

Отображает следующие сведения о текущем видео:

* Название
* Канал
* Длительность
* Дата загрузки
* Просмотры
* Лайки
* Комментарии
* Описание

### t: (временная метка / глава)

Отображает список временных меток или глав для видео (если автор включил эту информацию). Если дополнение сообщает «В этом видео не найдено глав», это означает, что видео просто не содержит данных о главах.

Это окно предлагает больше удобства, чем чтение глав из браузера:

* Поле поиска для фильтрации списка временных меток/глав — результаты обновляются мгновенно, без нажатия Enter
* Полный список отображается с описанием каждого раздела вначале, затем его временная позиция
* Область текста только для чтения для чтения длинных описаний глав
* Кнопка «Открыть главу» или нажатие Space/Enter для перехода непосредственно к этой главе в видео
* Кнопка «Копировать название» (Alt+C) для копирования названия главы
* Кнопка «Копировать URL» (Alt+U) для копирования URL с временной меткой для этой главы
* Кнопка «Экспорт» (Alt+E) для сохранения всех данных о временных метках/главах в текстовый файл

### g: (получить описание миниатюры)

Загружает изображение миниатюры и отправляет его в приложение **Be My Eyes** для живого описания, не покидая NVDA. Эта команда учитывает контекст: она описывает миниатюру видео, когда вы находитесь на странице видео, аватар канала, когда вы находитесь на странице канала, и обложку плейлиста, когда вы находитесь на странице плейлиста — используя тот же порядок определения URL, что и все остальные команды (сначала активное окно браузера, затем буфер обмена). Также доступна из меню «Действия» для видео (только миниатюры видео) и как настраиваемое быстрое действие (пробел).

Дополнение всегда выбирает изображение с самым высоким разрешением, сообщаемым yt-dlp, поэтому файл, отправляемый в Be My Eyes, является наилучшим из доступных.

Вы также можете описать аватар канала или обложку плейлиста непосредственно из окна «Избранное», без необходимости открывать эту страницу где-либо ещё — см. кнопки **Описать аватар** и **Описать обложку** в разделе [Избранное](#favorites) ниже.

**Примечание:** Для этого требуется, чтобы приложение [Be My Eyes](https://www.bemyeyes.com/) было установлено отдельно в вашей системе — дополнение не устанавливает и не включает его. Если оно не установлено, YoutubePlus предложит открыть его страницу в Microsoft Store, чтобы вы могли установить его сразу.

### Избранное

Окно, отображающее ваши сохранённые избранные элементы, разделённые на 5 вкладок по типу:

* **Видео:** Список сохранённых видео, организованных по категориям, которые вы создаёте сами. Дерево категорий находится слева, а список видео для выбранной категории — справа (см. [Категории](#categories-video--watch-list-tabs) ниже). Включает кнопки «Действия» и «Копировать» для каждого элемента (описаны ниже).
* **Канал:** Список сохранённых каналов с панелью описания канала. Включает кнопки для открытия канала, просмотра его контента по типу и описания его аватара через Be My Eyes (Alt+D).
* **Плейлист:** Список сохранённых плейлистов. Нажмите Space, Enter или Alt+V, чтобы развернуть все видео в плейлисте. Включает кнопку «Открыть в вебе» (Alt+W) и кнопку «Описать обложку» (Alt+D) для получения описания изображения обложки плейлиста через Be My Eyes.
* **Список для просмотра:** Список сохранённых видео с использованием той же раскладки «дерево категорий + список», что и на вкладке «Видео», со своим собственным независимым набором категорий.
* **История поиска:** Список всех выполненных вами поисков с возможностью повторного выполнения, удаления или очистки записей (см. [История поиска](#search-history) выше).

#### Команды окна «Избранное»

* Нажмите Control+1–Control+5 для переключения между вкладками
* Нажмите Control+Вверх/Вниз для изменения порядка вкладок
* Нажмите Control+C (копировать), Control+X (вырезать) или Control+V (вставить) для изменения порядка элементов
    * Избранные видео и список для просмотра поддерживают копирование и перемещение элементов друг между другом, включая элементы внутри категории. Вкладки «Видео» и «Список для просмотра» хранят отдельные списки категорий, поэтому при перемещении элемента между ними он помещается в ту категорию, которая выбрана на вкладке назначения. Избранные каналы и плейлисты поддерживают перемещение элементов только в пределах своего собственного списка.
* Нажмите Alt+R или Delete для удаления элемента
* Нажмите Alt+N для добавления нового элемента из буфера обмена — для вкладок каналов и плейлистов URL должен соответствовать типу вкладки
* Нажмите **Alt+O (Сортировка...)** для открытия диалога сортировки для текущей вкладки — см. [Сортировка](#sorting) ниже
* Поле поиска фильтрует результаты мгновенно по мере ввода — не нужно нажимать Enter

#### Категории (вкладки «Видео» и «Список для просмотра»)

Как на вкладке «Видео», так и на вкладке «Список для просмотра» вы можете организовывать элементы по собственным категориям, используя дерево слева, отдельное от списка элементов справа. Каждая вкладка хранит свои собственные категории — создание категории в одной не влияет на другую. Всегда существует узел по умолчанию для некатегоризированных элементов («Видео» на вкладке «Видео», «Список для просмотра» на вкладке «Список для просмотра»).

При фокусе на дереве категорий:

* Нажмите **Control+=**, чтобы добавить новую категорию
* Нажмите **F2**, чтобы переименовать выбранную категорию
* Нажмите **Delete**, чтобы удалить выбранную категорию — если она всё ещё содержит элементы, вам будет предложено переместить их в узел по умолчанию или удалить их вместе с категорией
* Нажмите **Control+Shift+Вверх** / **Control+Shift+Вниз**, чтобы изменить порядок выбранной категории
* Нажмите Enter или Tab, чтобы переместить фокус в список элементов для этой категории
* Щёлкните правой кнопкой мыши или нажмите клавишу Application/Menu для контекстного меню — его содержимое зависит от того, что выбрано: узел категории показывает параметры управления категориями (Добавить/Переименовать/Удалить/Переместить), в то время как узел по умолчанию показывает только «Добавить категорию»

При фокусе на списке элементов (правая сторона) щёлкните правой кнопкой мыши или нажмите клавишу Application/Menu для того же меню «Действия», которое используется во всём дополнении (Просмотр информации, Комментарии, Загрузка, Добавить в... и т. д.) — отдельно от контекстного меню категорий на дереве.

Вырезание, копирование и вставка в списке элементов работают, как описано выше, и вставка всегда помещает элементы в ту категорию, которая выбрана в данный момент в дереве.

#### Сортировка

Кнопка **Сортировка... (Alt+O)** доступна на любой вкладке с сортируемым списком — включая «Видео», «Список для просмотра» и «Историю поиска». Она открывает диалог с:

* **Сортировать по:** поле для сортировки (Название, Канал, Длительность, Дата загрузки, Дата добавления — поля незначительно различаются в зависимости от вкладки)
* **По возрастанию / По убыванию**
* **Сортировать только текущую категорию:** если отмечено, сортировка применяется только к элементам внутри категории, выбранной в данный момент в дереве, оставляя все остальные категории нетронутыми. По умолчанию не отмечено, что означает, что сортировка применяется ко всем категориям одновременно.
* **Применить постоянно (сохранить в файл):** если отмечено, новый порядок немедленно записывается на диск. Если не отмечено, сортировка является временной — она изменяет то, что вы видите сейчас, но отменяется при следующей перезагрузке списка или поиске.
* **Очистить сортировку:** отменяет любую временную сортировку и восстанавливает сохранённый порядок с диска.

#### Список видео

На вкладках видео и списка для просмотра, а также в любом другом представлении, показывающем список видео, вы найдёте кнопки **Действия...** и **Копировать...**. Это стандартные элементы управления для всех представлений списка видео, при этом лента подписок добавляет дополнительный пункт «Отписаться от этого канала».

Нажмите Enter на любом элементе, чтобы открыть видео в браузере, или нажмите пробел, чтобы выполнить быстрое действие, которое можно настроить в [настройках](#settings).

##### Кнопка «Действия»

Нажмите Alt+A, чтобы открыть меню «Действия», которое включает:

* Просмотреть информацию о видео... (i)
* Просмотреть комментарии / повтор... (c)
* Просмотреть главы/временные метки... (t)

* Загрузить видео (d)

* Добавить в избранные каналы (f)
* Добавить в список для просмотра (w)
* Открыть видео в браузере (b)
* Открыть канал в браузере (h)
* Показать видео канала (v)
* Показать шортсы канала (s)
* Показать прямые эфиры канала (l)
* Показать плейлисты канала (l)
* Показать подкасты канала (p)

Нажмите Alt+C, чтобы открыть меню «Копировать», которое включает:

* Копировать URL видео (u)
* Копировать имя канала (c)

### Лента подписок

Окно, отображающее видео с каналов, на которые вы подписаны в дополнении. Это отдельно от ваших подписок в аккаунте YouTube — не требуется привязка аккаунта или передача личных данных.

В отличие от окна «Избранное», это представление использует стандартные вкладки, разделённые по типу контента:

* **Все:** Все типы контента вместе
* **Видео:** Только обычные видео
* **Шортсы:** Только короткие видео
* **Прямые эфиры:** Прямые трансляции и их повторы

Помимо этих категорий по умолчанию, вы можете создавать собственные категории и настраивать, какие каналы отображаются в каждой из них.

#### Команды ленты подписок

* Нажмите Control+1–Control+0 для перехода к вкладке категории (до 10 категорий)
* Нажмите Control+Вверх/Вниз для изменения порядка категорий, как в окне «Избранное»
* Нажмите F2 для переименования категории (кроме 4 категорий по умолчанию)
* Нажмите Control+= для добавления новой категории
* Нажмите Control+- для удаления категории (кроме 4 категорий по умолчанию)
* Доступ к кнопкам «Действия» и «Копировать» для каждого видео или нажмите Enter, чтобы открыть его в браузере
* Нажмите Delete или Alt+S, чтобы отметить видео как просмотренное — оно будет удалено из списка
* Нажмите Control+Delete, чтобы отметить все видео на текущей вкладке как просмотренные

Дополнительные кнопки в этом окне:

* **Отметить как просмотренное (Alt+S)** — удаляет видео из списка; клавиша Delete также работает
* **Добавить новую подписку из URL в буфере обмена (Alt+N)** — подписывается на канал, используя URL, скопированный в буфер обмена
* **Обновить ленту (Alt+U)** — вручную запускает обновление для всех подписанных каналов; дополнение также автоматически обновляется при запуске NVDA по умолчанию
* **Ещё... (Alt+M)** — открывает подменю с дополнительными параметрами:
    * Отметить все на текущей вкладке как просмотренные (Ctrl+Delete) (a)
    * Показать все видео (включая просмотренные) (v) — переключает между показом только непросмотренных и всех видео; настройка сохраняется автоматически
    * Управление подписками... (m)
    * Добавить новую категорию... Ctrl+= (c)
    * Переименовать текущую категорию... F2 (r)
    * Удалить текущую категорию... Ctrl+-
    * Очистить все видео ленты... — удаляет все видео из базы данных без удаления ваших подписок; полезно, если база данных стала большой и влияет на производительность NVDA

### Управление подписками

Это окно показывает все каналы, на которые вы подписаны. Первый раздел — это список каналов, за которым следуют параметры управления для каждого канала:

* **Фильтр по категории** — фильтрует список каналов по категории; по умолчанию «Все»
* **Назначить категории** — выбирает, в каких категориях должен появляться контент этого канала
* **Типы контента для получения** — выбирает, какие типы контента обновлять для этого канала (Видео, Шортсы, Прямые эфиры); полезно для каналов, которые публикуют только определённые типы
* **Просмотреть контент... (Alt+C)** — просматривает контент канала, то же, что и кнопка «Действия»
* **Добавить новый канал для подписки из буфера обмена... (Alt+N)** — подписывается на новый канал, используя URL в буфере обмена
* **Отписаться от этого канала (Alt+U)** — удаляет канал из ваших подписок
* **Сохранить изменения** — **важно:** вы должны нажать эту кнопку перед закрытием окна, иначе ваши изменения не будут сохранены

### Управление профилями пользователей

Это окно управляет вашими профилями пользователей. Дополнение поставляется с профилем «по умолчанию». Здесь вы можете добавлять, удалять или переименовывать профили. Чтобы переключаться между профилями, перейдите на панель настроек дополнения.

В этом окне:

* Нажмите F2, чтобы переименовать выбранный профиль
* Нажмите Delete, чтобы удалить выбранный профиль

**Примечание:** Удаление профиля безвозвратно удаляет все данные, связанные с ним. Все сохранённые видео, каналы или подписки в этом профиле будут потеряны.

### l: (показать комментарии)

На видео YouTube существует три типа комментариев:

* **Комментарий** — стандартные комментарии зрителей на обычных видео
* **Живой чат** — сообщения, отправленные во время прямой трансляции
* **Повтор живого чата** — записанный живой чат для ранее транслировавшегося видео, если владелец канала не удалил его

YoutubePlus поддерживает доступ ко всем трём типам через эту команду.

#### Живой чат...

Для видео, которые транслируются в данный момент, нажмите L, и дополнение откроет новое окно, отображающее входящие сообщения чата. Отображаются только сообщения, полученные после активации команды — более ранние сообщения не захватываются.

Вы можете закрыть это окно и повторно открыть его позже с помощью команды V в слое YoutubePlus, пока трансляция ещё активна и NVDA не был перезапущен.

Используйте команду R, чтобы переключить, озвучивает ли NVDA новые сообщения вслух по мере их поступления. Это хорошо работает для трансляций с нечастыми сообщениями. Для трансляций с высоким потоком сообщений может быть удобнее отключить автоматическое чтение и прокручивать окно вручную.

Нажмите Shift+L, чтобы остановить мониторинг чата для текущего видео.

Три настройки напрямую влияют на эту функцию:

- **Автоматически озвучивать входящий живой чат:** Если отмечено, NVDA немедленно озвучивает новые сообщения — та же функция, что и команда R, но сохранённая как настройка по умолчанию.
- **Интервал обновления живого чата:** Как часто (в секундах) дополнение проверяет новые сообщения. По умолчанию 5 секунд.
- **Лимит истории сообщений:** Максимальное количество сообщений, хранящихся в памяти в течение сеанса. Окно живого чата показывает только самые последние сообщения до этого лимита (по умолчанию: 5 000). Дополнение хранит все сообщения в фоновом режиме для экспорта, до максимума 200 000, чтобы предотвратить чрезмерное использование памяти.

Когда трансляция заканчивается — или дополнение определяет, что она закончилась — автоматически появится диалог с вопросом, хотите ли вы экспортировать все собранные сообщения. Нажмите «Да», чтобы сохранить историю чата в файл.

#### Комментарии / Повтор живого чата

Для обычных загруженных видео или архивных трансляций вы можете получить доступ к комментариям таким же образом. Если доступны и повтор живого чата, и стандартные комментарии, появится диалог с вопросом, что вы хотите загрузить.

Лимит на количество отображаемых комментариев отсутствует, хотя загрузка может занять время для видео с большим количеством комментариев.

Комментарии отображаются с закреплёнными комментариями вначале, затем все остальные в порядке сортировки, настроенном в параметрах (сначала новые или сначала старые).

#### Разделы окна комментариев

* **Поле поиска** — введите текст для фильтрации комментариев; результаты обновляются мгновенно
* **Поле со списком фильтров** — выберите параметр фильтра (дополнение автоматически заполняет поле поиска):
    * Без фильтра — по умолчанию; показывает все комментарии
    * Фильтр по выбранному автору — показывает только комментарии от выбранного комментатора
    * Показать только Super Chats
    * Показать только Super Stickers
    * Показать только Super Thanks
* **Список комментариев** — показывает имя комментатора, а затем его сообщение
* **Область текста только для чтения** — прокручивайте полный текст выбранного комментария, полезно, когда комментарий слишком длинный, чтобы отображаться полностью в списке
* **Кнопка «Копировать» (Alt+C или Ctrl+C)** — копирует выбранный комментарий
* **Кнопка «Экспорт» (Alt+E)** — сохраняет все комментарии в текстовый файл в папку, установленную в настройках
* **Поле общей суммы платежей** — отображается только для повторов живого чата; показывает общую сумму пожертвований от зрителей во время трансляции

## Настройки

Доступ к настройкам через `NVDA -> Параметры -> Настройки...` и выберите категорию **«YoutubePlus»**.

- **Активный профиль:** Выберите профиль для использования. После переключения профиля требуется перезапуск.
- **Кнопка «Управление профилями»:** Открывает окно управления профилями пользователей.
- **Быстрое действие (пробел):** Выберите, что делает клавиша пробела в окнах со списком видео. Доступны все пункты из меню «Действия».
- **Режим уведомлений:** Выберите, как дополнение сигнализирует о фоновой активности:
  - *Звуковой сигнал:* Короткие звуковые сигналы
  - *Звук:* Аудиоэффект
  - *Без звука:* Без звукового уведомления (речевые ответы всё равно происходят)
- **Порядок сортировки по умолчанию:** Выберите, сортировать ли списки (комментарии, видео канала) **Сначала новые** или **Сначала старые**.
- **Количество элементов для получения:** Сколько элементов получать для каждого типа контента при просмотре канала и для обновлений ленты подписок. По умолчанию: 20.
- **Типы контента по умолчанию:** Выберите, какие типы контента получать для новых подписанных каналов: Видео, Шортсы и/или Прямые эфиры.
- **Интервал фонового обновления:** Как часто дополнение проверяет новый контент на подписанных каналах. Можно отключить или установить от 15 минут до 24 часов. Дополнение также автоматически обновляется при каждом запуске NVDA по умолчанию.
- **Автоматически озвучивать входящий живой чат:** Если отмечено, NVDA озвучивает новые сообщения чата по мере их поступления.
- **Интервал обновления живого чата:** Как часто (в секундах) дополнение проверяет новые сообщения. По умолчанию: 5 секунд.
- **Лимит истории сообщений:** Максимальное количество сообщений чата, хранящихся в памяти в течение сеанса.
- **Формат субтитров по умолчанию:** Формат файла субтитров для загрузки: SRT, VTT, TTML или TXT (обычный текст без временных меток)
- **Параметры качества и формата загрузки (Alt+D):** Сворачиваемый раздел (по умолчанию свёрнут — нажмите Alt+D в любом месте страницы настроек или активируйте его непосредственно, чтобы развернуть/свернуть), содержащий:
  - *Предпочтительное качество видео:* Наилучшее доступное или ограничение разрешения от 2160p до 360p.
  - *Предпочтительный контейнер видео:* MP4, MKV или WebM.
  - *Предпочтительное качество аудио (при преобразовании):* Наилучшее доступное или битрейт от 320 до 96 kbps. Применяется только если формат аудио ниже не «Наилучший доступный».
  - *Предпочтительный формат аудио:* Наилучший доступный (без преобразования, по умолчанию — загружает тот формат, который YouTube предлагает без изменений, FFmpeg не требуется) или преобразование в MP3, WAV, M4A/AAC, FLAC, Opus или Vorbis (OGG) — любое из этих преобразований требует FFmpeg, как и загрузка видео.
- **Метод получения cookies (Экспериментальный):** Выберите браузер, в котором вы вошли на YouTube. Дополнение извлечёт cookies из этого браузера для аутентификации запросов, что может помочь решить ошибку «Войдите, чтобы подтвердить, что вы не бот». Обратите внимание, что эта функция является экспериментальной, и результаты зависят от браузера и конфигурации системы.
- **Путь к папке загрузок и экспорта по умолчанию:** Папка назначения для загруженных видео/аудио и экспортированных чатов.
- **Создать резервную копию данных сейчас:** Вручную создаёт резервную копию всех данных для активного профиля. Дополнение также выполняет автоматическое ежедневное резервное копирование в фоновом режиме.
- **Восстановить данные из резервной копии:** Показывает список доступных резервных копий (до последних 5 дней), чтобы вы могли выбрать дату для восстановления.

### О yt-dlp

[yt-dlp](https://github.com/yt-dlp/yt-dlp) — один из самых мощных инструментов с открытым исходным кодом для загрузки видео и аудио с сайтов по всему миру — поддерживает более 1000 сайтов, не только YouTube. Он бесплатен, имеет открытый исходный код и активно поддерживается мировым сообществом, без рекламы и вредоносного ПО, в отличие от многих инструментов загрузки в браузере.

Тем не менее, пожалуйста, имейте в виду следующие рекомендации по использованию:

1. **Добросовестное использование:** Избегайте получения больших объёмов данных или отправки повторяющихся запросов за короткое время. YouTube может обнаружить необычную активность и временно ограничить доступ с вашего IP-адреса.
2. **Авторское право и конфиденциальность:** Любые полученные данные или контент должны использоваться только для личного просмотра или анализа. Пожалуйста, уважайте условия использования каждой платформы и не используйте данные способами, нарушающими авторские права.
3. **Ответственность:** Вы несёте ответственность за то, как вы используете это программное обеспечение. Разработчик дополнения предоставляет только интерфейс для доступа к данным YouTube через библиотеку yt-dlp.

**Совет:** Если вам нужно обрабатывать большие объёмы данных, распределяйте запросы по времени, чтобы поддерживать стабильность соединения и избегать ограничений доступа.
