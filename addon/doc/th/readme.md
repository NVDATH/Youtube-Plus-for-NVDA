# YoutubePlus for NVDA

> YoutubePlus เป็นส่วนเสริมสำหรับผู้ที่ชื่นชอบการใช้ YouTube แต่พบว่าฟีเจอร์หลายอย่างบนเว็บไซต์เข้าถึงได้ยาก — เช่น การอ่านความคิดเห็นในวิดีโอ
> เรานำฟีเจอร์เหล่านี้มาสู่คุณผ่านส่วนติดต่อผู้ใช้ของ NVDA ในรูปแบบที่นำทางได้ง่าย รองรับปุ่มลัด และปรับแต่งได้เต็มที่ — โดยไม่ต้องยุ่งกับ API Key หรือเชื่อมต่อบัญชีส่วนตัวใดๆ กับส่วนเสริมนี้เลย
> คุณสามารถติดตามช่องโปรดของคุณ และมั่นใจได้ว่าจะเห็นทุกวิดีโอจากช่องเหล่านั้น โดยไม่ถูกอัลกอริทึมของ YouTube กรองออกไป
> เรายังมีระบบรายการโปรดสำหรับวิดีโอ ช่อง เพลย์ลิสต์ และรายการเฝ้าดู เพื่อบันทึกเนื้อหาที่คุณสนใจแต่ยังไม่มีเวลาดู
> มีระบบค้นหาวิดีโอในตัวที่แสดงผลลัพธ์ภายในส่วนติดต่อผู้ใช้เดียวกันกับที่ใช้ทั่วทั้งส่วนเสริม — ไม่ใช่แค่ช่องค้นหาที่เปิด YouTube ในเบราว์เซอร์
> มีฟีเจอร์ดาวน์โหลดสำหรับบันทึกวิดีโอหรือไฟล์เสียง แม้จะเป็นฟีเจอร์เสริมมากกว่าจุดเด่นหลักของส่วนเสริมนี้ก็ตาม หากการดาวน์โหลดเป็นความต้องการหลักของคุณ มีส่วนเสริมอื่นที่ทำหน้าที่นี้โดยเฉพาะที่คุณอาจอยากลองดู
> สิ่งเดียวที่ส่วนเสริมนี้ไม่ทำคือการฝังตัวเล่นวิดีโอไว้ในตัว เราเชื่อว่าตัวเล่นวิดีโอบนเว็บของ YouTube เองก็เข้าถึงได้ดีอยู่แล้ว หากคุณรู้สึกว่ายังไม่พอ คุณสามารถใช้ส่วนเสริมอื่นเช่น [browserNav](https://addonstore.nvaccess.org/?channel=stable&language=en&apiVersion=2025.3.2&addonId=browsernav) เพื่อปรับปรุงประสบการณ์การใช้งานเพิ่มเติมได้

## ปุ่มลัดและคำสั่ง

ส่วนเสริมนี้ใช้ระบบปุ่มลัดแบบเลเยอร์เพื่อหลีกเลี่ยงการชนกับส่วนเสริมอื่นหรือคำสั่งของ NVDA
กด **NVDA+Y** เพื่อเข้าสู่โหมดคำสั่งของ YoutubePlus จากนั้นกดปุ่มใดปุ่มหนึ่งด้านล่างเพื่อเข้าถึงฟีเจอร์หรือหน้าต่างนั้นๆ

**หมายเหตุ:** หากปุ่มลัดหลัก (`NVDA+Y`) ชนกับส่วนเสริมอื่น คุณสามารถเปลี่ยนได้ผ่าน `NVDA -> Preferences -> Input Gestures...` ในหมวด "YoutubePlus"

### ปุ่มที่ใช้งานได้ในเลเยอร์ YoutubePlus

* a: (add to...) — เปิดเมนูย่อยให้คุณเลือกว่าจะเพิ่มวิดีโอหรือช่องปัจจุบันไปที่ใด
* f: (open favorites video) — เปิดหน้าต่างวิดีโอโปรด
* c: (open favorites channel) — เปิดหน้าต่างช่องโปรด
* p: (open favorites playlist) — เปิดหน้าต่างเพลย์ลิสต์โปรด
* w: (show watch list) — เปิดหน้าต่างรายการเฝ้าดู
* d: (download) — ถามยืนยันว่าจะดาวน์โหลดเป็นวิดีโอหรือเสียงอย่างเดียว
* e: (search) — เปิดหน้าต่างค้นหาวิดีโอ
* q: (quick search) — ค้นหา YouTube ทันทีโดยใช้ข้อความที่เลือกอยู่ในขณะนั้น หรือเนื้อหาในคลิปบอร์ดหากไม่ได้เลือกอะไรไว้ — โดยไม่ต้องเปิดกล่องค้นหาก่อน
* control+h: (search history) — เปิดหน้าต่างรายการโปรดตรงไปที่แท็บประวัติการค้นหาเลย
* i: (info) — เปิดหน้าต่างรายละเอียดวิดีโอ
* t: (show timestamp) — แสดงเวลาบทหรือบทต่างๆ ถ้ามี
* g: (get thumbnail description) — ดาวน์โหลดภาพปกของวิดีโอและส่งไปยังแอป Be My Eyes เพื่อขอคำอธิบายภาพแบบสด
* m: (open manage subscription) — เปิดหน้าต่างจัดการการติดตาม
* s: (open subscription feed) — แสดงวิดีโอจากช่องที่คุณติดตาม
* u: (open User Profile Manager) — เปิดหน้าต่างจัดการโปรไฟล์ผู้ใช้
* l: (show comment) — แสดงความคิดเห็น (รายละเอียดอธิบายด้านล่าง)
* shift+l: (stop monitor live chat) — หยุดการติดตามแชทสด
* r: (toggle automatic reading live chat) — เปิด/ปิดการอ่านออกเสียงข้อความแชทสดที่เข้ามาโดยอัตโนมัติ
* v: (show live chat) — เปิดหน้าต่างแชทสดกลับมาอีกครั้งหากคุณปิดไปขณะที่สตรีมยังดำเนินอยู่
* y: (open YoutubePlus settings dialog) เปิดหน้าตั้งค่าของ NVDA อย่างรวดเร็วแล้วโฟกัสไปที่หมวด YoutubePlus ทันที
* h: (help) — เปิดหน้าต่างแสดงรายการปุ่มลัดทั้งหมดที่ใช้ได้

**หมายเหตุ:** สำหรับคำสั่งที่ทำงานกับวิดีโอโดยตรง ส่วนเสริมจะเช็คหน้าต่างเบราว์เซอร์ที่เปิดอยู่ก่อน ถ้ามีหน้าวิดีโอ YouTube เปิดอยู่ จะใช้ URL ของวิดีโอนั้น ถ้าไม่มีหน้าวิดีโอเปิดอยู่ จะเช็คคลิปบอร์ดหา URL ของ YouTube แทน

## รายละเอียดฟีเจอร์และคำสั่ง

### a: (add to...)

คำสั่งนี้ในเลเยอร์ YoutubePlus จะส่งข้อมูลวิดีโอหรือช่องไปยังปลายทางที่คุณเลือก:

* Add to Favorite Videos (v)
* Add to Favorite Channels (c)
* Add to Favorite Playlist (p)
* Subscribe to Channel (s)
* Add to Watch List (w)

ส่วนเสริมจะเช็คหน้าเบราว์เซอร์ที่เปิดอยู่ก่อน ถ้าเป็นหน้าวิดีโอ YouTube จะดึง URL มาประมวลผลตามตัวเลือกที่คุณเลือกไว้ ถ้าหน้านั้นไม่ใช่วิดีโอ YouTube หรือไม่มีเบราว์เซอร์เปิดอยู่เลย จะเช็คคลิปบอร์ดหา URL ของ YouTube แทน

คำสั่งส่วนใหญ่ทำงานได้กับ URL ของ YouTube ทุกประเภท เพราะส่วนเสริมสามารถดึงข้อมูลที่จำเป็นออกมาเองได้ ตัวอย่างเช่น ถ้าคุณอยู่หน้าวิดีโอแล้วเลือก "Add to Favorite Channels" ส่วนเสริมจะดึง URL ของช่องออกมาให้อัตโนมัติ เช่นเดียวกับการติดตามช่อง

ข้อยกเว้นเดียวคือเพลย์ลิสต์ — คุณต้องเปิดหน้าเพลย์ลิสต์ของ YouTube อยู่ หรือมี URL เพลย์ลิสต์ที่ถูกต้องคัดลอกไว้ในคลิปบอร์ด

### d: (download video/audio)

คำสั่งนี้จะเปิดกล่องโต้ตอบเล็กๆ ถามว่าคุณต้องการดาวน์โหลดวิดีโอหรือเสียงอย่างเดียว คุณสามารถตั้งค่าปลายทางการดาวน์โหลด รวมถึงปรับคุณภาพ/รูปแบบไฟล์ได้ละเอียดขึ้น ในส่วนการตั้งค่า ([Settings](#การตั้งค่า))

**การดาวน์โหลดวิดีโอต้องใช้ FFmpeg** เนื่องจาก YouTube เลิกให้บริการวิดีโอส่วนใหญ่ในรูปแบบไฟล์เดียวที่รวมทั้งภาพและเสียงไว้ด้วยกันแล้ว การรวมสตรีมที่แยกกันจึงจำเป็นต้องใช้ FFmpeg YoutubePlus จะไม่แนบ FFmpeg มาในตัวส่วนเสริมเอง (เพื่อไม่ให้โฟลเดอร์ config ของ NVDA ของผู้ใช้แต่ละคนบวมขึ้นโดยไม่จำเป็น) — หากไม่พบ FFmpeg ในเครื่องตอนที่คุณดาวน์โหลดวิดีโอ และเครื่องมี `winget` ของ Windows อยู่ YoutubePlus จะเสนอให้ติดตั้งให้อัตโนมัติด้วยการถามใช่/ไม่ใช่เพียงครั้งเดียว เมื่อติดตั้งเสร็จแล้ว การดาวน์โหลดของคุณจะดำเนินต่อไปเองโดยอัตโนมัติ ไม่ต้องรีสตาร์ต NVDA เลย หากไม่มีทั้ง FFmpeg และ `winget` ระบบจะแจ้งให้ทราบและยกเลิกการดาวน์โหลดอย่างเรียบร้อย

การดาวน์โหลดเฉพาะเสียงไม่จำเป็นต้องใช้ FFmpeg ตามค่าเริ่มต้น จะต้องใช้ก็ต่อเมื่อคุณเลือกรูปแบบเสียงอื่นที่ไม่ใช่ "Best available (no conversion)" ในการตั้งค่ารูปแบบขั้นสูงด้านล่างเท่านั้น เพราะการแปลงเป็นรูปแบบเสียงอื่นก็ต้องผ่าน FFmpeg เช่นกัน

โปรดทราบว่าฟีเจอร์ดาวน์โหลดนี้มีไว้เพื่อความสะดวก และอาจมีข้อจำกัดหากใช้งานหนักมาก หากคุณต้องการดาวน์โหลดเนื้อหา YouTube จำนวนมาก แนะนำให้ใช้เครื่องมือเฉพาะทางอื่นแทน

### e: (search)

คำสั่งนี้จะเปิดหน้าต่างค้นหา YouTube พิมพ์คำค้นหาในช่องค้นหาแล้วกด Enter เพื่อค้นหาทันที คุณยังกด Tab เพื่อปรับจำนวนผลลัพธ์ที่จะแสดงได้ด้วย — ส่วนเสริมจะจดจำค่านี้ไว้ใช้ในการค้นหาครั้งต่อไป

ช่องค้นหาเป็นกล่องคอมโบที่จดจำการค้นหาก่อนหน้าของคุณ กดลูกศรลง (หรือ Alt+ลูกศรลง) เพื่อเปิดรายการคำค้นหาเก่าและเลือกใช้แทนการพิมพ์ใหม่

ผลลัพธ์จะแสดงในรูปแบบ [รายการวิดีโอ](#รายการวิดีโอ) เดียวกับที่ใช้ทั่วทั้งส่วนเสริม ไม่ใช่หน้าเว็บ YouTube คุณสามารถเข้าถึงรายละเอียดวิดีโอทั้งหมดได้เหมือนกับรายการวิดีโออื่นๆ ในส่วนเสริม

#### q: (quick search)

ทางเลือกที่เร็วกว่ากล่องค้นหาด้านบน เลือกข้อความในแอปพลิเคชันใดก็ได้ (หรือคัดลอกคำค้นหาไว้ในคลิปบอร์ดถ้าไม่ได้เลือกอะไร) แล้วกด Q ในเลเยอร์ YoutubePlus ส่วนเสริมจะค้นหา YouTube ทันทีด้วยข้อความนั้น โดยใช้จำนวนผลลัพธ์ที่บันทึกไว้จากการค้นหาครั้งล่าสุด — ไม่มีกล่องโต้ตอบ ไม่ต้องกดปุ่มเพิ่ม

#### ประวัติการค้นหา

ทุกการค้นหาที่คุณทำ — ไม่ว่าจะจากกล่องค้นหาหรือ quick search — จะถูกบันทึกโดยอัตโนมัติ กด **Control+H** ในเลเยอร์ YoutubePlus เพื่อไปที่แท็บประวัติการค้นหาในหน้าต่างรายการโปรดโดยตรง ซึ่งคุณสามารถ:

* กด Enter หรือปุ่ม **Search Again** เพื่อค้นหาซ้ำอีกครั้ง
* กด **New Search (Alt+N)** เพื่อเปิดกล่องค้นหา
* กด Delete หรือปุ่ม **Remove** เพื่อลบรายการเดียว
* กดปุ่ม **Clear All** เพื่อล้างประวัติทั้งหมด

### i: (video info)

แสดงรายละเอียดต่อไปนี้ของวิดีโอปัจจุบัน:

* ชื่อเรื่อง
* ช่อง
* ความยาว
* วันที่อัปโหลด
* ยอดวิว
* ยอดถูกใจ
* ความคิดเห็น
* คำอธิบาย

### t: (timestamp / chapter)

แสดงรายการเวลาบทหรือบทของวิดีโอ (ถ้าผู้สร้างใส่ข้อมูลนี้ไว้) หากส่วนเสริมแจ้งว่า "No chapters found in this video" แปลว่าวิดีโอนั้นไม่มีข้อมูลบทอยู่จริงๆ

หน้าต่างนี้สะดวกกว่าการอ่านบทจากเบราว์เซอร์ตรงที่:

* มีช่องค้นหาเพื่อกรองรายการเวลาบท/บท — ผลลัพธ์อัปเดตทันทีโดยไม่ต้องกด Enter
* แสดงรายการทั้งหมดโดยขึ้นคำอธิบายของแต่ละส่วนก่อน ตามด้วยตำแหน่งเวลา
* มีกล่องข้อความอ่านอย่างเดียวสำหรับอ่านคำอธิบายบทที่ยาว
* ปุ่ม "Open Chapter" — หรือกด Space หรือ Enter — เพื่อกระโดดไปยังบทนั้นในวิดีโอทันที
* ปุ่ม Copy Title (Alt+C) เพื่อคัดลอกชื่อบท
* ปุ่ม Copy URL (Alt+U) เพื่อคัดลอก URL พร้อมเวลาของบทนั้น
* ปุ่ม Export (Alt+E) เพื่อบันทึกข้อมูลเวลาบท/บททั้งหมดเป็นไฟล์ข้อความ

### g: (get thumbnail description)

ดาวน์โหลดภาพและส่งไปยังแอป **Be My Eyes** เพื่อขอคำอธิบายภาพแบบสด โดยไม่ต้องออกจาก NVDA คำสั่งนี้รู้บริบทของหน้าที่เปิดอยู่โดยอัตโนมัติ — ถ้าอยู่หน้าวิดีโอจะบรรยายภาพปกวิดีโอ ถ้าอยู่หน้าช่องจะบรรยายรูปโปรไฟล์ช่อง และถ้าอยู่หน้าเพลย์ลิสต์จะบรรยายภาพปกเพลย์ลิสต์ — ใช้ลำดับการตรวจจับ URL แบบเดียวกับคำสั่งอื่นๆ (เช็คหน้าต่างเบราว์เซอร์ที่เปิดอยู่ก่อน แล้วค่อยเช็ค Clipboard) นอกจากนี้ยังเรียกใช้ได้จากเมนู Action ของวิดีโอ (เฉพาะภาพปกวิดีโอ) หรือกำหนดให้เป็น Quick Action (Space bar) ก็ได้

ส่วนเสริมจะเลือกภาพที่มีความละเอียดสูงสุดเท่าที่ yt-dlp รายงานไว้เสมอ เพื่อให้ได้ไฟล์ที่ส่งไปยัง Be My Eyes ดีที่สุดเท่าที่มี

นอกจากนี้ยังขอคำอธิบายรูปโปรไฟล์ช่องหรือภาพปกเพลย์ลิสต์ได้โดยตรงจากหน้าต่าง Favorites โดยไม่ต้องเปิดหน้านั้นๆ เลย — ดูปุ่ม **Describe Avatar** และ **Describe Cover** ใน [Favorites](#รายการโปรด) ด้านล่าง

**หมายเหตุ:** ฟีเจอร์นี้ต้องติดตั้งแอป [Be My Eyes](https://www.bemyeyes.com/) แยกต่างหากในเครื่องของคุณเอง — ส่วนเสริมนี้ไม่ได้ติดตั้งหรือแนบแอปดังกล่าวมาให้ หากยังไม่ได้ติดตั้งไว้ YoutubePlus จะเสนอเปิดหน้า Microsoft Store ของแอปให้ทันที เพื่อให้ติดตั้งได้เลย

### รายการโปรด

หน้าต่างแสดงรายการโปรดที่คุณบันทึกไว้ แบ่งออกเป็น 5 แท็บตามประเภท:

* **Video:** แสดงรายการวิดีโอที่บันทึกไว้ จัดกลุ่มเป็นหมวดหมู่ที่คุณสร้างเอง มีแผนผังหมวดหมู่อยู่ทางซ้าย และรายการวิดีโอของหมวดหมู่ที่เลือกอยู่ทางขวา (ดู [Categories](#หมวดหมู่-แท็บ-video-และ-watch-list) ด้านล่าง) มีปุ่ม Action และ Copy สำหรับแต่ละรายการ (อธิบายด้านล่าง)
* **Channel:** แสดงรายการช่องที่บันทึกไว้ พร้อมแผงคำอธิบายช่อง มีปุ่มเปิดช่อง เรียกดูเนื้อหาตามประเภท และขอคำอธิบายรูปโปรไฟล์ผ่าน Be My Eyes (Alt+D)
* **Playlist:** แสดงรายการเพลย์ลิสต์ที่บันทึกไว้ กด Space, Enter หรือ Alt+V เพื่อขยายดูวิดีโอทั้งหมดในเพลย์ลิสต์ มีปุ่ม Open on Web (Alt+W) และปุ่ม Describe Cover (Alt+D) เพื่อขอคำอธิบายภาพปกเพลย์ลิสต์ผ่าน Be My Eyes
* **Watch List:** แสดงรายการวิดีโอที่บันทึกไว้ ใช้รูปแบบแผนผังหมวดหมู่ + รายการเดียวกับแท็บ Video แต่มีชุดหมวดหมู่เป็นของตัวเองแยกต่างหาก
* **Search History:** แสดงทุกการค้นหาที่คุณเคยทำ พร้อมตัวเลือกค้นหาซ้ำ ลบ หรือล้างรายการ (ดู [ประวัติการค้นหา](#ประวัติการค้นหา) ด้านบน)

#### คำสั่งในหน้าต่าง Favorites

* กด Control+1 ถึง Control+5 เพื่อสลับระหว่างแท็บ
* กด Control+ลูกศรขึ้น/ลง เพื่อจัดลำดับแท็บใหม่
* กด Control+C (copy), Control+X (cut), หรือ Control+V (paste) เพื่อจัดลำดับรายการใหม่
    * แท็บ Favorite Videos และ Watch List รองรับการคัดลอกและย้ายรายการระหว่างกันได้ รวมถึงรายการภายในหมวดหมู่ด้วย แท็บ Video และ Watch List ต่างเก็บรายการหมวดหมู่ของตัวเองแยกกัน ดังนั้นเมื่อย้ายรายการระหว่างแท็บ รายการนั้นจะถูกวางไว้ในหมวดหมู่ที่กำลังเลือกอยู่ในแท็บปลายทาง แท็บ Favorite Channels และ Playlists รองรับแค่การย้ายรายการภายในรายการของตัวเองเท่านั้น
* กด Alt+R หรือ Delete เพื่อลบรายการ
* กด Alt+N เพื่อเพิ่มรายการใหม่จากคลิปบอร์ด — สำหรับแท็บช่องและเพลย์ลิสต์ URL ต้องตรงกับประเภทของแท็บนั้น
* กด **Alt+O (Sort...)** เพื่อเปิดกล่องโต้ตอบจัดเรียงสำหรับแท็บปัจจุบัน — ดู [Sorting](#การจัดเรียง) ด้านล่าง
* ช่องค้นหาจะกรองผลลัพธ์ทันทีขณะพิมพ์ — ไม่ต้องกด Enter

#### หมวดหมู่ (แท็บ Video และ Watch List)

ทั้งแท็บ Video และ Watch List ให้คุณจัดระเบียบรายการเป็นหมวดหมู่ของตัวเองได้ ผ่านมุมมองแผนผังทางซ้าย แยกจากรายการทางขวา แต่ละแท็บมีหมวดหมู่เป็นของตัวเอง — การสร้างหมวดหมู่ในแท็บหนึ่งจะไม่กระทบอีกแท็บ จะมีโหนดค่าเริ่มต้นสำหรับรายการที่ไม่มีหมวดหมู่เสมอ ("Videos" ในแท็บ Video, "Watch List" ในแท็บ Watch List)

เมื่อโฟกัสอยู่ที่แผนผังหมวดหมู่:

* กด **Control+=** เพื่อเพิ่มหมวดหมู่ใหม่
* กด **F2** เพื่อเปลี่ยนชื่อหมวดหมู่ที่เลือก
* กด **Delete** เพื่อลบหมวดหมู่ที่เลือก — ถ้ายังมีรายการอยู่ในนั้น ระบบจะถามว่าจะย้ายไปโหนดค่าเริ่มต้นหรือลบไปพร้อมกับหมวดหมู่
* กด **Control+Shift+ลูกศรขึ้น** / **Control+Shift+ลูกศรลง** เพื่อจัดลำดับหมวดหมู่ที่เลือกใหม่
* กด Enter หรือ Tab เพื่อย้ายโฟกัสไปที่รายการวิดีโอของหมวดหมู่นั้น
* คลิกขวา หรือกดปุ่ม Application/Menu เพื่อเปิดเมนูบริบท — เนื้อหาขึ้นอยู่กับสิ่งที่เลือกไว้: โหนดหมวดหมู่จะแสดงตัวเลือกจัดการหมวดหมู่ (เพิ่ม/เปลี่ยนชื่อ/ลบ/ย้าย) ส่วนโหนดค่าเริ่มต้นจะแสดงแค่ Add Category

เมื่อโฟกัสอยู่ที่รายการ (ทางขวา) คลิกขวาหรือกดปุ่ม Application/Menu เพื่อเปิดเมนู Action เดียวกับที่ใช้ทั่วทั้งส่วนเสริม (View Info, Comments, Download, Add to... ฯลฯ) — แยกจากเมนูบริบทของหมวดหมู่บนแผนผัง

การ Cut, Copy, และ Paste บนรายการทำงานตามที่อธิบายไว้ด้านบน และการ paste จะวางรายการไว้ในหมวดหมู่ที่กำลังเลือกอยู่บนแผนผังเสมอ

#### การจัดเรียง

ปุ่ม **Sort... (Alt+O)** ใช้ได้กับทุกแท็บที่มีรายการจัดเรียงได้ — รวมถึง Video, Watch List, และ Search History เมื่อกดจะเปิดกล่องโต้ตอบที่มี:

* **Sort by:** ฟิลด์ที่ใช้จัดเรียง (Title, Channel, Duration, Upload Date, Date Added — ฟิลด์จะต่างกันเล็กน้อยตามแท็บ)
* **Ascending / Descending**
* **Sort only the current category:** เมื่อเปิดใช้ การจัดเรียงจะจัดแค่รายการภายในหมวดหมู่ที่กำลังเลือกอยู่บนแผนผังเท่านั้น หมวดหมู่อื่นจะไม่ถูกแตะต้อง ค่าเริ่มต้นปิดไว้ หมายความว่าการจัดเรียงจะใช้กับทุกหมวดหมู่พร้อมกัน
* **Apply permanently (saves to file):** เมื่อเปิดใช้ ลำดับใหม่จะถูกบันทึกลงดิสก์ทันที ถ้าปิดไว้ การจัดเรียงจะเป็นแบบชั่วคราว — เปลี่ยนสิ่งที่คุณเห็นตอนนี้เท่านั้น แล้วจะกลับเป็นเดิมเมื่อรายการโหลดใหม่หรือคุณค้นหา
* **Clear Sort:** ยกเลิกการจัดเรียงชั่วคราวใดๆ และคืนค่าลำดับที่บันทึกไว้จากดิสก์

#### รายการวิดีโอ

ในแท็บ Video และ Watch List รวมถึงมุมมองอื่นๆ ที่แสดงรายการวิดีโอ คุณจะพบปุ่ม **Action...** และ **Copy...** ซึ่งเป็นตัวควบคุมมาตรฐานในทุกมุมมองรายการวิดีโอ โดยฟีดการติดตามจะมีตัวเลือกเพิ่มเติม "Unsubscribe from this channel"

กด Enter บนรายการใดก็ได้เพื่อเปิดวิดีโอในเบราว์เซอร์ หรือกด Space bar เพื่อทำ Quick Action ที่คุณตั้งค่าไว้ได้จาก [Settings](#การตั้งค่า)

### ฟีดการติดตาม

หน้าต่างแสดงวิดีโอจากช่องที่คุณติดตามภายในส่วนเสริม แยกต่างหากจากการติดตาม (subscriptions) บัญชี YouTube ของคุณ — ไม่ต้องเชื่อมบัญชีหรือใช้ข้อมูลส่วนตัวใดๆ

ต่างจากหน้าต่าง Favorites มุมมองนี้ใช้แท็บมาตรฐานแบ่งตามประเภทเนื้อหา:

* **All:** ทุกประเภทเนื้อหารวมกัน
* **Video:** วิดีโอทั่วไปเท่านั้น
* **Shorts:** วิดีโอสั้นเท่านั้น
* **Live:** การถ่ายทอดสดและการเล่นซ้ำการถ่ายทอดสด

นอกจากหมวดหมู่ค่าเริ่มต้นเหล่านี้ คุณยังสร้างหมวดหมู่กำหนดเองและตั้งค่าว่าช่องไหนจะปรากฏในหมวดหมู่ไหนได้

#### คำสั่งในฟีดการติดตาม

* กด Control+1 ถึง Control+0 เพื่อกระโดดไปแท็บหมวดหมู่ (สูงสุด 10 หมวดหมู่)
* กด Control+ลูกศรขึ้น/ลง เพื่อจัดลำดับหมวดหมู่ใหม่ เหมือนในหน้าต่าง Favorites
* กด F2 เพื่อเปลี่ยนชื่อหมวดหมู่ (ยกเว้น 4 หมวดหมู่ค่าเริ่มต้น)
* กด Control+= เพื่อเพิ่มหมวดหมู่ใหม่
* กด Control+- เพื่อลบหมวดหมู่ (ยกเว้น 4 หมวดหมู่ค่าเริ่มต้น)
* เข้าถึงปุ่ม Action และ Copy ของแต่ละวิดีโอ หรือกด Enter เพื่อเปิดในเบราว์เซอร์
* กด Delete หรือ Alt+S เพื่อทำเครื่องหมายวิดีโอว่าเห็นแล้ว — จะถูกเอาออกจากรายการ
* กด Control+Delete เพื่อทำเครื่องหมายวิดีโอทั้งหมดในแท็บปัจจุบันว่าเห็นแล้ว

ปุ่มเพิ่มเติมในหน้าต่างนี้:

* **Mark as seen (Alt+S)** — เอาวิดีโอออกจากรายการ ปุ่ม Delete ก็ใช้ได้เช่นกัน
* **Add new Subscription from clipboard URL (Alt+N)** — ติดตามช่องโดยใช้ URL ที่คัดลอกไว้ในคลิปบอร์ด
* **Update Feed (Alt+U)** — สั่งอัปเดตช่องที่ติดตามทั้งหมดด้วยตนเอง โดยค่าเริ่มต้นส่วนเสริมจะอัปเดตอัตโนมัติทุกครั้งที่เปิด NVDA อยู่แล้ว
* **More... (Alt+M)** — เปิดเมนูย่อยที่มีตัวเลือกเพิ่มเติม:
    * Mark all in current tab as seen (Ctrl+Delete) (a)
    * Show all videos (including seen) (v) — สลับระหว่างแสดงเฉพาะที่ยังไม่เห็นกับแสดงทั้งหมด ค่านี้จะถูกบันทึกอัตโนมัติ
    * Manage subscriptions... (m)
    * Add New Category... Ctrl+= (c)
    * Rename Current Category... F2 (r)
    * Remove Current Category... Ctrl+-
    * Clear All Feed Videos... — ลบวิดีโอทั้งหมดออกจากฐานข้อมูลโดยไม่ยกเลิกการติดตาม มีประโยชน์เมื่อฐานข้อมูลใหญ่ขึ้นจนกระทบประสิทธิภาพของ NVDA

### จัดการการติดตาม

หน้าต่างนี้แสดงช่องทั้งหมดที่คุณติดตามอยู่ ส่วนแรกคือรายการช่อง ตามด้วยตัวเลือกจัดการสำหรับแต่ละช่อง:

* **Filter by Category** — กรองรายการช่องตามหมวดหมู่ ค่าเริ่มต้นคือ "All"
* **Assign to Categories** — เลือกว่าเนื้อหาของช่องนี้ควรปรากฏในหมวดหมู่ไหนบ้าง
* **Content Types to Fetch** — เลือกประเภทเนื้อหาที่จะอัปเดตสำหรับช่องนี้ (Videos, Shorts, Live) มีประโยชน์สำหรับช่องที่เผยแพร่แค่บางประเภทเท่านั้น
* **View Content... (Alt+C)** — เรียกดูเนื้อหาของช่อง เหมือนปุ่ม Action
* **Add new subscribe channel from Clipboard... (Alt+N)** — ติดตามช่องใหม่โดยใช้ URL ในคลิปบอร์ด
* **Unsubscribe from this Channel (Alt+U)** — เลิกติดตามช่องนี้
* **Save Changes** — **สำคัญ:** คุณต้องกดปุ่มนี้ก่อนปิดหน้าต่าง ไม่เช่นนั้นการเปลี่ยนแปลงจะไม่ถูกบันทึก

### ตัวจัดการโปรไฟล์ผู้ใช้

หน้าต่างนี้จัดการโปรไฟล์ผู้ใช้ของคุณ ส่วนเสริมมาพร้อมโปรไฟล์ "default" คุณสามารถเพิ่ม ลบ หรือเปลี่ยนชื่อโปรไฟล์ได้ที่นี่ หากต้องการสลับโปรไฟล์ ให้ไปที่หน้าตั้งค่าของส่วนเสริม

ในหน้าต่างนี้:

* กด F2 เพื่อเปลี่ยนชื่อโปรไฟล์ที่เลือก
* กด Delete เพื่อลบโปรไฟล์ที่เลือก

**หมายเหตุ:** การลบโปรไฟล์จะลบข้อมูลทั้งหมดที่เกี่ยวข้องอย่างถาวร วิดีโอ ช่อง หรือการติดตามที่บันทึกไว้ในโปรไฟล์นั้นจะหายไป

### l: (show comments)

วิดีโอ YouTube มีความคิดเห็น 3 ประเภท:

* **Comment** — ความคิดเห็นทั่วไปของผู้ชมในวิดีโอปกติ
* **Live chat** — ข้อความที่ส่งระหว่างการถ่ายทอดสด
* **Live chat replay** — บันทึกแชทสดของวิดีโอที่เคยถ่ายทอดสดมาก่อน หากเจ้าของช่องไม่ได้ลบออก

YoutubePlus รองรับการเข้าถึงทั้ง 3 ประเภทผ่านคำสั่งนี้

#### Live chat of...

สำหรับวิดีโอที่กำลังถ่ายทอดสดอยู่ กด L แล้วส่วนเสริมจะเปิดหน้าต่างใหม่แสดงข้อความแชทที่เข้ามา จะแสดงเฉพาะข้อความที่ได้รับหลังจากคุณสั่งคำสั่งนี้เท่านั้น — ข้อความก่อนหน้าจะไม่ถูกดักจับ

คุณสามารถปิดหน้าต่างนี้แล้วเปิดใหม่ภายหลังด้วยคำสั่ง V ในเลเยอร์ YoutubePlus ได้ ตราบใดที่สตรีมยังดำเนินอยู่และยังไม่ได้รีสตาร์ต NVDA

ใช้คำสั่ง R เพื่อเปิด/ปิดว่า NVDA จะอ่านข้อความใหม่ออกเสียงเมื่อเข้ามาหรือไม่ วิธีนี้เหมาะกับสตรีมที่มีข้อความไม่บ่อยนัก สำหรับสตรีมที่มีข้อความจำนวนมาก อาจง่ายกว่าถ้าปิดการอ่านอัตโนมัติแล้วเลื่อนดูหน้าต่างเอง

กด Shift+L เพื่อหยุดติดตามแชทสำหรับวิดีโอปัจจุบัน

มี 3 การตั้งค่าที่ส่งผลโดยตรงกับฟีเจอร์นี้:

- **Automatically speak incoming live chat:** เมื่อเปิดใช้ NVDA จะอ่านข้อความใหม่ออกเสียงทันที — ทำงานเหมือนคำสั่ง R แต่บันทึกไว้เป็นค่าเริ่มต้น
- **Live chat refresh interval:** ความถี่ (เป็นวินาที) ที่ส่วนเสริมจะเช็คข้อความใหม่ ค่าเริ่มต้นคือ 5 วินาที
- **Message history limit:** จำนวนข้อความสูงสุดที่เก็บไว้ในหน่วยความจำระหว่างเซสชัน หน้าต่างแชทสดจะแสดงแค่ข้อความล่าสุดตามจำนวนนี้ (ค่าเริ่มต้น: 5,000) ส่วนเสริมจะเก็บข้อความทั้งหมดไว้เบื้องหลังสำหรับการส่งออก สูงสุดถึง 200,000 ข้อความ เพื่อป้องกันการใช้หน่วยความจำมากเกินไป

เมื่อสตรีมจบลง — หรือส่วนเสริมตรวจพบว่าจบแล้ว — จะมีกล่องโต้ตอบเด้งขึ้นมาอัตโนมัติถามว่าคุณต้องการส่งออกข้อความทั้งหมดที่เก็บไว้หรือไม่ กด Yes เพื่อบันทึกประวัติแชทเป็นไฟล์

#### Comments / Live chat replay

สำหรับวิดีโอที่อัปโหลดทั่วไปหรือสตรีมที่บันทึกไว้ คุณสามารถเข้าถึงความคิดเห็นได้แบบเดียวกัน หากมีทั้ง live chat replay และความคิดเห็นปกติให้เลือก จะมีกล่องโต้ตอบถามว่าต้องการโหลดอะไร

ไม่มีการจำกัดจำนวนความคิดเห็นที่แสดง แม้ว่าการโหลดอาจใช้เวลาสำหรับวิดีโอที่มีความคิดเห็นจำนวนมาก

ความคิดเห็นจะแสดงโดยเรียงความคิดเห็นที่ปักหมุดไว้ก่อน ตามด้วยความคิดเห็นอื่นๆ ตามลำดับที่ตั้งไว้ในการตั้งค่า (ใหม่สุดก่อน หรือ เก่าสุดก่อน)

#### ส่วนต่างๆ ในหน้าต่างความคิดเห็น

* **ช่องค้นหา** — พิมพ์เพื่อกรองความคิดเห็น ผลลัพธ์อัปเดตทันที
* **กล่องคอมโบตัวกรอง** — เลือกตัวกรอง (ส่วนเสริมจะเติมช่องค้นหาให้อัตโนมัติ):
    * No Filter — ค่าเริ่มต้น แสดงความคิดเห็นทั้งหมด
    * Filter by Selected Author — แสดงเฉพาะความคิดเห็นจากผู้แสดงความคิดเห็นที่เลือกไว้
    * Show Super Chats Only
    * Show Super Stickers Only
    * Show Super Thanks Only
* **รายการความคิดเห็น** — แสดงชื่อผู้แสดงความคิดเห็นตามด้วยข้อความของเขา
* **กล่องข้อความอ่านอย่างเดียว** — เลื่อนอ่านข้อความเต็มของความคิดเห็นที่เลือก มีประโยชน์เมื่อความคิดเห็นยาวเกินกว่าจะแสดงเต็มในรายการ
* **ปุ่ม Copy (Alt+C หรือ Ctrl+C)** — คัดลอกความคิดเห็นที่เลือก
* **ปุ่ม Export (Alt+E)** — บันทึกความคิดเห็นทั้งหมดเป็นไฟล์ข้อความไปที่โฟลเดอร์ที่ตั้งไว้ในการตั้งค่า
* **ช่องยอดเงินบริจาครวม** — แสดงเฉพาะกรณี live chat replay เท่านั้น แสดงยอดบริจาครวมจากผู้ชมระหว่างสตรีม

## การตั้งค่า

เข้าถึงการตั้งค่าผ่าน `NVDA -> Preferences -> Settings...` แล้วเลือกหมวด **"YoutubePlus"**

- **Active Profile:** เลือกโปรไฟล์ที่จะใช้ ต้องรีสตาร์ตหลังสลับโปรไฟล์
- **Manage Profile button:** เปิดหน้าต่างตัวจัดการโปรไฟล์ผู้ใช้
- **Quick Action (Space bar):** เลือกว่าปุ่ม Space จะทำอะไรในหน้าต่างรายการวิดีโอ มีตัวเลือกทั้งหมดจากเมนู Action ให้เลือก
- **Notification mode:** เลือกวิธีที่ส่วนเสริมแจ้งการทำงานเบื้องหลัง:
  - *Beep:* เสียงบี๊บสั้นๆ
  - *Sound:* เอฟเฟกต์เสียง
  - *Silent:* ไม่มีเสียงแจ้งเตือน (ข้อความพูดยังคงมีอยู่)
- **Default sort order:** เลือกว่ารายการ (ความคิดเห็น วิดีโอในช่อง) จะเรียง **Newest First** หรือ **Oldest First**
- **Items to fetch:** จำนวนรายการที่จะดึงต่อประเภทเนื้อหาเมื่อเรียกดูช่อง และสำหรับการอัปเดตฟีดการติดตาม ค่าเริ่มต้น: 20
- **Default content types:** เลือกประเภทเนื้อหาที่จะดึงสำหรับช่องที่ติดตามใหม่: Videos, Shorts และ/หรือ Live
- **Background update interval:** ความถี่ที่ส่วนเสริมจะเช็คเนื้อหาใหม่จากช่องที่ติดตาม สามารถปิดหรือตั้งได้ตั้งแต่ 15 นาทีถึง 24 ชั่วโมง โดยค่าเริ่มต้นส่วนเสริมจะอัปเดตอัตโนมัติทุกครั้งที่เปิด NVDA ด้วย
- **Automatically speak incoming live chat:** เมื่อเปิดใช้ NVDA จะอ่านข้อความแชทใหม่ออกเสียงเมื่อเข้ามา
- **Live chat refresh interval:** ความถี่ (เป็นวินาที) ที่ส่วนเสริมจะเช็คข้อความใหม่ ค่าเริ่มต้น: 5 วินาที
- **Message history limit:** จำนวนข้อความแชทสูงสุดที่เก็บไว้ในหน่วยความจำระหว่างเซสชัน
- **Default subtitle format:** รูปแบบไฟล์คำบรรยายสำหรับการดาวน์โหลด: SRT, VTT, TTML หรือ TXT (ข้อความล้วนไม่มีเวลากำกับ)
- **Download Quality and Format Options (Alt+D):** ส่วนที่พับเก็บได้ (ปิดไว้เป็นค่าเริ่มต้น — กด Alt+D จากตำแหน่งไหนก็ได้ในหน้าตั้งค่า หรือกดที่ตัวควบคุมโดยตรง เพื่อขยาย/ย่อ) ประกอบด้วย:
  - *Preferred video quality:* Best available หรือกำหนดเพดานความละเอียดตั้งแต่ 2160p ลงมาถึง 360p
  - *Preferred video container:* MP4, MKV หรือ WebM
  - *Preferred audio quality (when converting):* Best available หรือ bitrate ตั้งแต่ 320 ลงมาถึง 96 kbps ใช้ได้เฉพาะเมื่อรูปแบบเสียงด้านล่างไม่ใช่ "Best available"
  - *Preferred audio format:* Best available (ไม่แปลงไฟล์ เป็นค่าเริ่มต้น — ดาวน์โหลดตามรูปแบบที่ YouTube ให้มาโดยตรง ไม่ต้องใช้ FFmpeg) หรือแปลงเป็น MP3, WAV, M4A/AAC, FLAC, Opus หรือ Vorbis (OGG) — การแปลงทุกแบบนี้ต้องใช้ FFmpeg เหมือนกับการดาวน์โหลดวิดีโอ
- **Cookie method (Experimental):** เลือกเบราว์เซอร์ที่คุณล็อกอิน YouTube อยู่ ส่วนเสริมจะดึงคุกกี้จากเบราว์เซอร์นั้นมายืนยันตัวตนคำขอ ซึ่งอาจช่วยแก้ error "Sign in to confirm you're not a bot" ได้ โปรดทราบว่าฟีเจอร์นี้ยังอยู่ในขั้นทดลอง ผลลัพธ์อาจแตกต่างกันตามเบราว์เซอร์และการตั้งค่าระบบ
- **Default download and export folder path:** โฟลเดอร์ปลายทางสำหรับวิดีโอ/เสียงที่ดาวน์โหลด และแชทที่ส่งออก
- **Backup data now:** สำรองข้อมูลทั้งหมดของโปรไฟล์ที่ใช้งานอยู่ด้วยตนเอง ส่วนเสริมยังสำรองข้อมูลอัตโนมัติทุกวันในพื้นหลังด้วย
- **Restore data from backup:** แสดงรายการไฟล์สำรองที่มี (ย้อนหลังได้ถึง 5 วัน) ให้คุณเลือกวันที่จะกู้คืน

## ข้อมูลเพิ่มเติม

ส่วนเสริมนี้พึ่งพาไลบรารีหลัก 2 ตัว: [pytchat](https://pypi.org/project/pytchat/) สำหรับติดตามแชทสด และ [yt-dlp](https://pypi.org/project/yt-dlp/) สำหรับการเข้าถึงข้อมูล YouTube อื่นๆ ทั้งหมด เราขอขอบคุณนักพัฒนาของทั้งสองไลบรารีอย่างจริงใจ

### เกี่ยวกับ yt-dlp

[yt-dlp](https://github.com/yt-dlp/yt-dlp) เป็นหนึ่งในเครื่องมือโอเพนซอร์สที่ทรงพลังที่สุดสำหรับดาวน์โหลดวิดีโอและเสียงจากเว็บไซต์ทั่วโลก — รองรับกว่า 1,000 เว็บไซต์ ไม่ใช่แค่ YouTube เท่านั้น เป็นซอฟต์แวร์ฟรี โอเพนซอร์ส และได้รับการดูแลอย่างต่อเนื่องโดยชุมชนทั่วโลก ไม่มีโฆษณาหรือมัลแวร์ ต่างจากเครื่องมือดาวน์โหลดแบบเว็บเบราว์เซอร์หลายตัว

อย่างไรก็ตาม โปรดคำนึงถึงแนวทางการใช้งานต่อไปนี้:

1. **Fair Use:** หลีกเลี่ยงการดึงข้อมูลจำนวนมากหรือส่งคำขอซ้ำๆ ในเวลาสั้นๆ YouTube อาจตรวจพบกิจกรรมที่ผิดปกติและจำกัดการเข้าถึงจาก IP ของคุณชั่วคราว
2. **ลิขสิทธิ์และความเป็นส่วนตัว:** ข้อมูลหรือเนื้อหาใดๆ ที่ดึงมาควรใช้เพื่อรับชมหรือวิเคราะห์ส่วนตัวเท่านั้น โปรดเคารพข้อตกลงการใช้งานของแต่ละแพลตฟอร์ม และอย่านำข้อมูลไปใช้ในทางที่ละเมิดลิขสิทธิ์
3. **ความรับผิดชอบ:** คุณเป็นผู้รับผิดชอบต่อวิธีที่คุณใช้ซอฟต์แวร์นี้ ผู้พัฒนาส่วนเสริมนี้จัดเตรียมเพียงส่วนติดต่อสำหรับเข้าถึงข้อมูล YouTube ผ่านไลบรารี yt-dlp เท่านั้น

**เคล็ดลับ:** หากคุณต้องประมวลผลข้อมูลจำนวนมาก ควรเว้นระยะเวลาระหว่างคำขอเพื่อรักษาความเสถียรของการเชื่อมต่อและหลีกเลี่ยงข้อจำกัดในการเข้าถึง
