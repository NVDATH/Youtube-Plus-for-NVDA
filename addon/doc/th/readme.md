# YoutubePlus สำหรับ NVDA

> YoutubePlus เป็นส่วนเสริมสำหรับผู้ที่ชอบใช้ YouTube แต่พบว่าฟีเจอร์หลายอย่างบนเว็บไซต์เข้าถึงได้ยาก เช่น การอ่านความคิดเห็นของวิดีโอ
> เรานำฟีเจอร์เหล่านี้มาให้คุณใช้งานผ่านส่วนติดต่อผู้ใช้ของ NVDA ในรูปแบบที่นำทางได้ง่าย รองรับปุ่มลัด และปรับแต่งได้อย่างเต็มที่ โดยไม่ต้องจัดการคีย์ API หรือเชื่อมต่อบัญชีส่วนตัวกับส่วนเสริม
> คุณสามารถติดตามช่องโปรดและมั่นใจได้ว่าจะเห็นวิดีโอทุกคลิปจากช่องเหล่านั้น โดยไม่มีอัลกอริทึมของ YouTube คัดกรองออก
> เรายังมีระบบรายการโปรดสำหรับวิดีโอ ช่อง และเพลย์ลิสต์ รวมถึงรายการดูภายหลังสำหรับบันทึกเนื้อหาที่สนใจแต่ยังไม่มีเวลาดู
> มีระบบค้นหาวิดีโอในตัวที่แสดงผลการค้นหาในส่วนติดต่อเดียวกับที่ใช้ทั่วทั้งส่วนเสริม ไม่ใช่เพียงช่องค้นหาที่เปิด YouTube ในเบราว์เซอร์
> มีฟีเจอร์ดาวน์โหลดเพื่อบันทึกวิดีโอหรือไฟล์เสียงด้วย แต่จัดไว้เพื่อความสะดวก ไม่ใช่จุดเน้นหลัก หากการดาวน์โหลดเป็นความต้องการหลักของคุณ อาจลองใช้ส่วนเสริมอื่นที่ออกแบบมาเพื่อการนี้โดยเฉพาะ
> สิ่งหนึ่งที่ส่วนเสริมนี้ไม่มีคือเครื่องเล่นวิดีโอแบบฝังในตัว เราเชื่อว่าเครื่องเล่นบนเว็บไซต์ YouTube เข้าถึงได้ดีเพียงพออยู่แล้ว หากคุณยังพบข้อจำกัด สามารถใช้ส่วนเสริมอื่น เช่น [browserNav](https://addonstore.nvaccess.org/?channel=stable&language=en&apiVersion=2025.3.2&addonId=browsernav) เพื่อปรับปรุงประสบการณ์ใช้งานได้

## ปุ่มลัดและคำสั่ง

ส่วนเสริมนี้ใช้ระบบปุ่มลัดแบบเป็นชั้น เพื่อลดการชนกับส่วนเสริมอื่นหรือคำสั่งของ NVDA
กด **NVDA+Y** เพื่อเข้าสู่โหมดคำสั่งของ YoutubePlus จากนั้นกดปุ่มใดปุ่มหนึ่งต่อไปนี้เพื่อเปิดฟีเจอร์หรือหน้าต่างที่ต้องการ

**หมายเหตุ:** หากปุ่มลัดหลัก (`NVDA+Y`) ชนกับส่วนเสริมอื่น คุณสามารถเปลี่ยนได้ที่ `NVDA -> Preferences -> Input Gestures...` (NVDA -> การตั้งค่า -> กำหนดปุ่มคำสั่ง...) ในหมวด “YoutubePlus”

### ปุ่มที่ใช้ได้ในชั้นคำสั่ง YoutubePlus

* a: (เพิ่มไปยัง...) — เปิดเมนูย่อยเพื่อเลือกว่าจะเพิ่มวิดีโอหรือช่องปัจจุบันไปที่ใด
* f: (เปิดวิดีโอโปรด) — เปิดหน้าต่างวิดีโอโปรด
* c: (เปิดช่องโปรด) — เปิดหน้าต่างช่องโปรด
* p: (เปิดเพลย์ลิสต์โปรด) — เปิดหน้าต่างเพลย์ลิสต์โปรด
* w: (แสดงรายการดูภายหลัง) — เปิดหน้าต่างรายการดูภายหลัง
* d: (ดาวน์โหลด) — ถามเพื่อยืนยันว่าจะดาวน์โหลดเป็นวิดีโอหรือเฉพาะเสียง
* e: (ค้นหา) — เปิดหน้าต่างค้นหาวิดีโอ
* q: (ค้นหาด่วน) — ค้นหา YouTube ทันทีโดยใช้ข้อความที่เลือกอยู่ หรือข้อความในคลิปบอร์ดหากไม่ได้เลือกข้อความ โดยไม่ต้องเปิดกล่องโต้ตอบค้นหาก่อน
* control+h: (ประวัติการค้นหา) — เปิดหน้าต่างรายการโปรดที่แท็บประวัติการค้นหาโดยตรง
* i: (ข้อมูล) — เปิดหน้าต่างรายละเอียดวิดีโอ
* t: (แสดงจุดเวลาหรือบท) — แสดงจุดเวลาหรือบทของวิดีโอ หากมี
* g: (รับคำอธิบายภาพขนาดย่อ) — ดาวน์โหลดภาพขนาดย่อของวิดีโอแล้วส่งไปยังแอป Be My Eyes เพื่อรับคำอธิบายภาพทันที
* m: (เปิดการจัดการช่องที่ติดตาม) — เปิดหน้าต่างจัดการช่องที่ติดตาม
* s: (เปิดฟีดช่องที่ติดตาม) — แสดงวิดีโอจากช่องที่คุณติดตาม
* u: (เปิดตัวจัดการโปรไฟล์ผู้ใช้) — เปิดหน้าต่างจัดการโปรไฟล์ผู้ใช้
* l: (แสดงความคิดเห็น) — แสดงความเห็นต่าง ๆ โดยมีรายละเอียดด้านล่าง
* shift+l: (หยุดติดตามแชทสด) — หยุดการติดตามแชทสด
* r: (เปิด/ปิดการอ่านแชทสดอัตโนมัติ) — เปิดหรือปิดการอ่านข้อความแชทสดที่เข้ามาโดยอัตโนมัติ หากใช้โปรไฟล์เสียง คำสั่งนี้จะหยุดเสียงแชททันทีด้วย
* v: (แสดงแชทสด) — เปิดหน้าต่างแชทสดอีกครั้ง หากคุณปิดหน้าต่างไปขณะที่การถ่ายทอดสดยังดำเนินอยู่
* y: (เปิดการตั้งค่า YoutubePlus) — เปิดการตั้งค่า NVDA และย้ายโฟกัสไปยังหมวด YoutubePlus อย่างรวดเร็ว
* h: (วิธีใช้) — เปิดหน้าต่างแสดงปุ่มลัดทั้งหมดที่ใช้ได้

**หมายเหตุ:** สำหรับคำสั่งที่ทำงานกับวิดีโอโดยตรง ส่วนเสริมจะตรวจสอบหน้าต่างเบราว์เซอร์ที่เปิดอยู่ก่อน หากหน้าที่ใช้งานอยู่เป็นหน้าวิดีโอ YouTube จะใช้ URL ของวิดีโอนั้น หากไม่ได้เปิดหน้าวิดีโอไว้ จะตรวจหา URL ของ YouTube ในคลิปบอร์ด

## รายละเอียดฟีเจอร์และคำสั่ง

### a: (เพิ่มไปยัง...)

คำสั่งนี้ในชั้นคำสั่ง YoutubePlus จะส่งข้อมูลวิดีโอหรือช่องไปยังปลายทางที่เลือก:

* เพิ่มไปยังวิดีโอโปรด (v)
* เพิ่มไปยังช่องโปรด (c)
* เพิ่มไปยังเพลย์ลิสต์โปรด (p)
* ติดตามช่อง (s)
* เพิ่มไปยังรายการดูภายหลัง (w)

ส่วนเสริมจะตรวจสอบหน้าเบราว์เซอร์ที่เปิดอยู่ก่อน หากเป็นหน้าวิดีโอ YouTube จะดึง URL และดำเนินการตามที่คุณเลือก หากหน้าเว็บไม่ใช่วิดีโอ YouTube หรือไม่ได้เปิดเบราว์เซอร์ไว้ จะตรวจหา URL ของ YouTube ในคลิปบอร์ด

คำสั่งส่วนใหญ่ใช้กับ URL ของ YouTube ได้ทุกประเภท เพราะส่วนเสริมสามารถดึงข้อมูลที่ต้องการจาก URL นั้นได้ เช่น หากคุณอยู่ในหน้าวิดีโอแล้วเลือก “เพิ่มไปยังช่องโปรด” ส่วนเสริมจะดึง URL ของช่องให้โดยอัตโนมัติ การติดตามช่องก็ทำงานในลักษณะเดียวกัน

ข้อยกเว้นเพียงอย่างเดียวคือเพลย์ลิสต์ คุณต้องเปิดหน้าเพลย์ลิสต์ YouTube ไว้ หรือคัดลอก URL เพลย์ลิสต์ YouTube ที่ถูกต้องลงในคลิปบอร์ด

### d: (ดาวน์โหลดวิดีโอ/เสียง)

คำสั่งนี้เปิดกล่องโต้ตอบขนาดเล็กเพื่อถามว่าต้องการดาวน์โหลดวิดีโอหรือเฉพาะเสียง คุณกำหนดโฟลเดอร์ปลายทางและปรับคุณภาพ/รูปแบบได้ในหัวข้อ [การตั้งค่า](#settings)

**การดาวน์โหลดวิดีโอต้องใช้ FFmpeg** ปัจจุบัน YouTube ไม่ได้ให้วิดีโอส่วนใหญ่เป็นไฟล์เดียวที่รวมภาพและเสียงอีกต่อไป จึงต้องใช้ FFmpeg รวมสตรีมภาพและเสียงที่แยกกัน YoutubePlus ไม่ได้แนบ FFmpeg มาด้วย เพื่อไม่ให้โฟลเดอร์การตั้งค่า NVDA ของผู้ใช้ทุกคนมีขนาดใหญ่ขึ้น หากไม่พบ FFmpeg ในระบบขณะดาวน์โหลดวิดีโอ และมีเครื่องมือ `winget` ของ Windows ส่วนเสริมจะเสนอให้ติดตั้งโดยอัตโนมัติผ่านคำถามยืนยันใช่/ไม่ใช่เพียงครั้งเดียว เมื่อติดตั้งเสร็จ การดาวน์โหลดจะดำเนินต่อโดยอัตโนมัติ ไม่ต้องเริ่ม NVDA ใหม่ หากไม่มีทั้ง FFmpeg และ `winget` ส่วนเสริมจะแจ้งให้ทราบและยกเลิกการดาวน์โหลดอย่างเรียบร้อย

ตามค่าเริ่มต้น การดาวน์โหลดเฉพาะเสียงไม่ต้องใช้ FFmpeg จะต้องใช้ก็ต่อเมื่อคุณเลือกรูปแบบเสียงอื่นนอกเหนือจาก “Best available (no conversion)” หรือ “ดีที่สุดที่มี (ไม่แปลงรูปแบบ)” ในการตั้งค่ารูปแบบขั้นสูงด้านล่าง เพราะการแปลงรูปแบบเสียงก็ใช้ FFmpeg เช่นกัน

โปรดทราบว่าฟีเจอร์ดาวน์โหลดจัดไว้เพื่อความสะดวก และอาจมีข้อจำกัดหากใช้งานอย่างหนัก หากต้องดาวน์โหลดเนื้อหา YouTube จำนวนมาก แนะนำให้ใช้เครื่องมือที่ออกแบบมาเพื่อการดาวน์โหลดโดยเฉพาะ

### e: (ค้นหา)

คำสั่งนี้เปิดหน้าต่างค้นหา YouTube พิมพ์คำค้นในช่องค้นหาแล้วกด Enter เพื่อค้นหาทันที คุณสามารถกด Tab ไปปรับจำนวนผลลัพธ์ที่ต้องการแสดงได้ ส่วนเสริมจะจำค่านี้ไว้สำหรับการค้นหาครั้งต่อไป

ช่องค้นหาเป็นกล่องคำสั่งผสมที่จดจำคำค้นที่ผ่านมา กดลูกศรลง หรือ Alt+ลูกศรลง เพื่อเปิดรายการคำค้นก่อนหน้า แล้วเลือกคำที่ต้องการแทนการพิมพ์ใหม่

ใต้ช่องคำค้นมีตัวกรองสี่รายการเพื่อจำกัดผลลัพธ์ โดยใช้ร่วมกันได้อย่างอิสระ เช่น ค้นหาเพลย์ลิสต์ที่อัปโหลดเดือนนี้และเรียงตามจำนวนการดู:

* **ประเภทเนื้อหา:** วิดีโอ (ค่าเริ่มต้น), ช่อง หรือเพลย์ลิสต์
* **ระยะเวลา:** ทั้งหมด, สั้น (น้อยกว่า 4 นาที), ปานกลาง (4–20 นาที) หรือยาว (มากกว่า 20 นาที)
* **วันที่อัปโหลด:** ทั้งหมด, ชั่วโมงที่ผ่านมา, วันนี้, สัปดาห์นี้, เดือนนี้ หรือปีนี้
* **เรียงตาม:** ความเกี่ยวข้อง (ค่าเริ่มต้น), วันที่อัปโหลด หรือจำนวนการดู

ผลลัพธ์จะแสดงในรูปแบบ [รายการวิดีโอ](#video-list) เดียวกับที่ใช้ทั่วทั้งส่วนเสริม ไม่ใช่หน้าเว็บ YouTube ผลลัพธ์ประเภทช่องจะเปิดหรือคัดลอก URL ของช่อง และมีเมนูการดำเนินการที่ลดตัวเลือกลง โดยไม่มีการดาวน์โหลด ความคิดเห็น หรือคำสั่งที่ใช้ได้เฉพาะกับวิดีโอ ส่วนผลลัพธ์ประเภทเพลย์ลิสต์จะเปิดเป็นรายการวิดีโอภายในเพลย์ลิสต์ เช่นเดียวกับเพลย์ลิสต์โปรด

#### ค้นหาภายในช่อง

ช่อง **Within channel (ภายในช่อง)** จะจำกัดการค้นหาให้เหลือเฉพาะวิดีโอของช่องใดช่องหนึ่ง แทนการค้นหาทั่ว YouTube เมื่อกำหนดช่องแล้ว ตัวกรองทั้งสี่ด้านบนจะถูกซ่อน เพราะใช้กับหน้าค้นหาภายในช่องไม่ได้

เริ่มพิมพ์ชื่อช่อง แล้วรายการแบบเลื่อนลงจะแนะนำช่องจากประวัติการค้นหา ช่องโปรด และช่องที่ติดตาม หากข้อความที่พิมพ์ไม่ตรงกับรายการเหล่านั้น เช่น เป็นช่องที่คุณไม่เคยค้นหาหรือเพิ่มเป็นรายการโปรดมาก่อน ส่วนเสริมจะค้นหาใน YouTube แล้วแสดงหน้าต่างให้คุณยืนยันช่องที่ต้องการ โดยจะไม่เดาให้เองโดยไม่แจ้ง คุณสามารถวาง URL ของช่องโดยตรงแทนการพิมพ์ชื่อได้ด้วย

คุณยังเปิดกล่องโต้ตอบนี้พร้อมระบุช่องไว้ล่วงหน้าได้ โดยเลือกช่องในแท็บ Channel ของหน้าต่างรายการโปรด แล้วกดปุ่ม **Search in this channel... (ค้นหาในช่องนี้...)**

#### q: (ค้นหาด่วน)

เป็นทางเลือกที่เร็วกว่ากล่องโต้ตอบค้นหาด้านบน เลือกข้อความในแอปใดก็ได้ หรือคัดลอกคำค้นไว้ในคลิปบอร์ดหากไม่ได้เลือกข้อความ จากนั้นกด Q ในชั้นคำสั่ง YoutubePlus ส่วนเสริมจะค้นหา YouTube ทันทีโดยใช้ข้อความนั้นและจำนวนผลลัพธ์ที่บันทึกจากการค้นหาครั้งล่าสุด โดยไม่มีกล่องโต้ตอบหรือการกดปุ่มเพิ่มเติม

#### ประวัติการค้นหา

การค้นหาทุกครั้ง ทั้งจากกล่องโต้ตอบค้นหาและการค้นหาด่วน จะถูกบันทึกโดยอัตโนมัติพร้อมตัวกรองที่ใช้ รวมถึงช่องที่กำหนดใน “Within channel” กด **Control+H** ในชั้นคำสั่ง YoutubePlus เพื่อไปยังแท็บประวัติการค้นหาในหน้าต่างรายการโปรดโดยตรง ซึ่งคุณสามารถ:

* กด Enter หรือปุ่ม **Search Again (ค้นหาอีกครั้ง)** เพื่อค้นหาซ้ำด้วยตัวกรองเดิมทุกประการ หรือใช้ช่องเดิมหากเป็นการค้นหาภายในช่อง รายการแบบนี้จะแสดงเป็น “คำค้น (ใน ชื่อช่อง)” เพื่อให้เห็นได้ทันที
* กด **New Search (ค้นหาใหม่) (Alt+N)** เพื่อเปิดกล่องโต้ตอบค้นหา
* กด Delete หรือปุ่ม **Remove (ลบ)** เพื่อลบรายการเดียว
* กดปุ่ม **Clear All (ล้างทั้งหมด)** เพื่อล้างประวัติทั้งหมด

### i: (ข้อมูลวิดีโอ)

แสดงรายละเอียดต่อไปนี้ของวิดีโอปัจจุบัน:

* ชื่อวิดีโอ
* ช่อง
* ระยะเวลา
* วันที่อัปโหลด
* จำนวนการดู
* จำนวนการกดชอบ
* จำนวนความคิดเห็น
* คำอธิบาย

### t: (จุดเวลา / บท)

แสดงรายการจุดเวลาหรือบทของวิดีโอ หากผู้สร้างใส่ข้อมูลนี้ไว้ หากส่วนเสริมแจ้งว่า “No chapters found in this video” หมายความว่าวิดีโอนั้นไม่มีข้อมูลบท

หน้าต่างนี้มีสิ่งอำนวยความสะดวกมากกว่าการอ่านบทผ่านเบราว์เซอร์:

* ช่องค้นหาเพื่อกรองรายการจุดเวลา/บท โดยผลลัพธ์เปลี่ยนทันที ไม่ต้องกด Enter
* รายการทั้งหมดแสดงคำอธิบายแต่ละส่วนก่อน ตามด้วยตำแหน่งเวลา
* พื้นที่ข้อความแบบอ่านอย่างเดียวสำหรับอ่านคำอธิบายบทที่ยาว
* ปุ่ม “Open Chapter (เปิดบท)” หรือกด Space หรือ Enter เพื่อข้ามไปยังบทนั้นในวิดีโอโดยตรง
* ปุ่ม Copy Title (คัดลอกชื่อ) (Alt+C) เพื่อคัดลอกชื่อบท
* ปุ่ม Copy URL (คัดลอก URL) (Alt+U) เพื่อคัดลอก URL ที่มีตำแหน่งเวลาของบทนั้น
* ปุ่ม Export (ส่งออก) (Alt+E) เพื่อบันทึกข้อมูลจุดเวลา/บททั้งหมดเป็นไฟล์ข้อความ

### g: (รับคำอธิบายภาพขนาดย่อ)

ดาวน์โหลดภาพขนาดย่อและส่งไปยังแอป **Be My Eyes** เพื่อรับคำอธิบายภาพทันที โดยไม่ต้องออกจาก NVDA คำสั่งนี้ทำงานตามบริบท: อธิบายภาพขนาดย่อเมื่ออยู่ในหน้าวิดีโอ อธิบายรูปประจำช่องเมื่ออยู่ในหน้าช่อง และอธิบายภาพปกเมื่ออยู่ในหน้าเพลย์ลิสต์ โดยตรวจหา URL ตามลำดับเดียวกับคำสั่งอื่น คือหน้าต่างเบราว์เซอร์ที่ใช้งานอยู่ก่อน แล้วจึงตรวจคลิปบอร์ด นอกจากนี้ยังเรียกได้จากเมนู Action ของวิดีโอ ซึ่งอธิบายได้เฉพาะภาพขนาดย่อวิดีโอ และกำหนดเป็นการดำเนินการด่วนด้วยปุ่ม Space ได้

ส่วนเสริมจะเลือกภาพที่มีความละเอียดสูงสุดตามที่ yt-dlp รายงานเสมอ เพื่อให้ไฟล์ที่ส่งไปยัง Be My Eyes เป็นภาพที่ดีที่สุดที่มี

คุณยังอธิบายรูปประจำช่องหรือภาพปกเพลย์ลิสต์ได้โดยตรงจากหน้าต่างรายการโปรด โดยไม่ต้องเปิดหน้าเว็บนั้นไว้ ดูปุ่ม **Describe Avatar (อธิบายรูปประจำช่อง)** และ **Describe Cover (อธิบายภาพปก)** ในหัวข้อ [รายการโปรด](#favorites) ด้านล่าง

**หมายเหตุ:** ต้องติดตั้งแอป [Be My Eyes](https://www.bemyeyes.com/) แยกต่างหาก ส่วนเสริมไม่ได้ติดตั้งหรือแนบแอปมาด้วย หากยังไม่ได้ติดตั้ง YoutubePlus จะเสนอให้เปิดหน้า Microsoft Store ของแอปเพื่อให้ติดตั้งได้ทันที

<a id="favorites"></a>
### รายการโปรด

หน้าต่างแสดงรายการโปรดที่บันทึกไว้ แบ่งตามประเภทเป็น 5 แท็บ:

* **Video (วิดีโอ):** แสดงวิดีโอที่บันทึกไว้ โดยจัดเป็นหมวดหมู่ที่คุณสร้างเอง ด้านซ้ายเป็นแผนผังหมวดหมู่ ส่วนด้านขวาเป็นรายการวิดีโอของหมวดหมู่ที่เลือก ดูหัวข้อ [หมวดหมู่](#categories-video--watch-list-tabs) ด้านล่าง แต่ละรายการมีปุ่ม Action และ Copy ตามคำอธิบายด้านล่าง
* **Channel (ช่อง):** แสดงช่องที่บันทึกไว้พร้อมแผงคำอธิบายช่อง มีปุ่มเปิดช่อง เรียกดูเนื้อหาตามประเภท ค้นหาภายในช่อง และอธิบายรูปประจำช่องผ่าน Be My Eyes (Alt+D)
* **Playlist (เพลย์ลิสต์):** แสดงเพลย์ลิสต์ที่บันทึกไว้ กด Space, Enter หรือ Alt+V เพื่อแสดงวิดีโอทั้งหมดภายในเพลย์ลิสต์ มีปุ่ม Open on Web (เปิดบนเว็บ) (Alt+W) และ Describe Cover (อธิบายภาพปก) (Alt+D) เพื่อรับคำอธิบายภาพปกจาก Be My Eyes
* **Watch List (รายการดูภายหลัง):** แสดงวิดีโอที่บันทึกไว้โดยใช้รูปแบบแผนผังหมวดหมู่และรายการเช่นเดียวกับแท็บ Video แต่มีชุดหมวดหมู่แยกจากกัน
* **Search History (ประวัติการค้นหา):** แสดงการค้นหาทุกครั้ง พร้อมตัวเลือกค้นหาซ้ำ ลบ หรือล้างรายการ ดูหัวข้อ [ประวัติการค้นหา](#search-history) ด้านบน

#### คำสั่งในหน้าต่างรายการโปรด

* กด Control+1 ถึง Control+5 เพื่อสลับแท็บ
* กด Control+ลูกศรขึ้น/ลง เพื่อเปลี่ยนลำดับแท็บ
* กด Control+C (คัดลอก), Control+X (ตัด) หรือ Control+V (วาง) เพื่อจัดลำดับรายการ
  * วิดีโอโปรดและรายการดูภายหลังรองรับการคัดลอกและย้ายรายการระหว่างกัน รวมถึงรายการภายในหมวดหมู่ แต่ละแท็บมีชุดหมวดหมู่ของตนเอง เมื่อย้ายรายการข้ามแท็บ รายการจะถูกวางในหมวดหมู่ที่เลือกอยู่ในแท็บปลายทาง ส่วนช่องโปรดและเพลย์ลิสต์โปรดรองรับเฉพาะการย้ายภายในรายการของตัวเอง
* กด Alt+R หรือ Delete เพื่อลบรายการ
* กด Alt+N เพื่อเพิ่มรายการใหม่จากคลิปบอร์ด สำหรับแท็บช่องและเพลย์ลิสต์ URL ต้องตรงกับประเภทของแท็บ
* กด **Alt+O (Sort... / เรียงลำดับ...)** เพื่อเปิดกล่องโต้ตอบเรียงลำดับของแท็บปัจจุบัน ดูหัวข้อ [การเรียงลำดับ](#sorting) ด้านล่าง
* ช่องค้นหาจะกรองผลลัพธ์ทันทีที่พิมพ์ ไม่ต้องกด Enter

<a id="categories-video--watch-list-tabs"></a>
#### หมวดหมู่ (แท็บ Video และ Watch List)

ทั้งแท็บ Video และ Watch List ให้คุณจัดรายการเป็นหมวดหมู่ของตัวเอง โดยใช้มุมมองแผนผังด้านซ้ายแยกจากรายการด้านขวา แต่ละแท็บมีหมวดหมู่ของตัวเอง การสร้างหมวดหมู่ในแท็บหนึ่งไม่ส่งผลต่ออีกแท็บ จะมีโหนดเริ่มต้นสำหรับรายการที่ยังไม่ได้จัดหมวดหมู่เสมอ คือ “Videos” ในแท็บ Video และ “Watch List” ในแท็บ Watch List

เมื่อโฟกัสอยู่บนแผนผังหมวดหมู่:

* กด **Control+=** เพื่อเพิ่มหมวดหมู่ใหม่
* กด **F2** เพื่อเปลี่ยนชื่อหมวดหมู่ที่เลือก
* กด **Delete** เพื่อลบหมวดหมู่ที่เลือก หากยังมีรายการอยู่ภายใน จะมีคำถามว่าจะย้ายรายการไปยังโหนดเริ่มต้น หรือลบไปพร้อมกับหมวดหมู่
* กด **Control+Shift+ลูกศรขึ้น** / **Control+Shift+ลูกศรลง** เพื่อเปลี่ยนลำดับหมวดหมู่ที่เลือก
* กด Enter หรือ Tab เพื่อย้ายโฟกัสไปยังรายการของหมวดหมู่นั้น
* คลิกขวาหรือกดปุ่ม Application/Menu เพื่อเปิดเมนูบริบท เนื้อหาเมนูขึ้นอยู่กับสิ่งที่เลือก หากเลือกโหนดหมวดหมู่ จะมีตัวเลือกเพิ่ม เปลี่ยนชื่อ ลบ และย้าย ส่วนโหนดเริ่มต้นมีเพียงตัวเลือกเพิ่มหมวดหมู่

เมื่อโฟกัสอยู่ในรายการด้านขวา ให้คลิกขวาหรือกดปุ่ม Application/Menu เพื่อเปิดเมนู Action แบบเดียวกับที่ใช้ทั่วทั้งส่วนเสริม เช่น ดูข้อมูล ความคิดเห็น ดาวน์โหลด เพิ่มไปยัง... เป็นต้น เมนูนี้แยกจากเมนูบริบทของหมวดหมู่ในแผนผัง

การตัด คัดลอก และวางในรายการทำงานตามที่อธิบายไว้ข้างต้น และการวางจะนำรายการไปไว้ในหมวดหมู่ที่เลือกอยู่ในแผนผังเสมอ

#### การเรียงลำดับ

ปุ่ม **Sort... (เรียงลำดับ...) (Alt+O)** ใช้ได้ในแท็บที่มีรายการซึ่งเรียงลำดับได้ รวมถึง Video, Watch List และ Search History โดยเปิดกล่องโต้ตอบที่มีตัวเลือก:

* **Sort by (เรียงตาม):** ช่องข้อมูลที่ใช้เรียง เช่น ชื่อ ช่อง ระยะเวลา วันที่อัปโหลด วันที่เพิ่ม โดยแต่ละแท็บอาจมีช่องข้อมูลต่างกันเล็กน้อย
* **Ascending / Descending (จากน้อยไปมาก / จากมากไปน้อย)**
* **Sort only the current category (เรียงเฉพาะหมวดหมู่ปัจจุบัน):** เมื่อเลือก จะเปลี่ยนลำดับเฉพาะรายการในหมวดหมู่ที่เลือกอยู่ในแผนผัง โดยไม่เปลี่ยนหมวดหมู่อื่น ค่าเริ่มต้นไม่ได้เลือก หมายความว่าจะเรียงทุกหมวดหมู่พร้อมกัน
* **Apply permanently (saves to file) (ใช้ถาวรและบันทึกลงไฟล์):** เมื่อเลือก จะบันทึกลำดับใหม่ลงดิสก์ทันที หากไม่เลือก การเรียงจะมีผลชั่วคราวเฉพาะที่เห็นในขณะนั้น และกลับเป็นลำดับเดิมเมื่อโหลดรายการใหม่หรือค้นหา
* **Clear Sort (ล้างการเรียงลำดับ):** ยกเลิกการเรียงชั่วคราวและคืนลำดับที่บันทึกไว้บนดิสก์

#### รายการวิดีโอ

ในแท็บวิดีโอและรายการดูภายหลัง รวมถึงมุมมองอื่นที่แสดงรายการวิดีโอ คุณจะพบปุ่ม **Action... (การดำเนินการ...)** และ **Copy... (คัดลอก...)** ซึ่งเป็นตัวควบคุมมาตรฐานในทุกมุมมองรายการวิดีโอ โดยฟีดช่องที่ติดตามจะมีตัวเลือก “เลิกติดตามช่องนี้” เพิ่มเติม

กด Enter บนรายการใดก็ได้เพื่อเปิดวิดีโอในเบราว์เซอร์ หรือกด Space เพื่อทำการดำเนินการด่วนที่กำหนดไว้ใน [การตั้งค่า](#settings)

* ดูความคิดเห็น / แชทย้อนหลัง... (c)
* ดูบท/จุดเวลา... (t)
* รับคำอธิบายภาพขนาดย่อ (Be My Eyes)... (g)
* ดาวน์โหลดวิดีโอ (d)
* ดาวน์โหลดเสียง (a)
* เพิ่มไปยังวิดีโอโปรด (f)
* เพิ่มไปยังช่องโปรด (f)
* เพิ่มไปยังรายการดูภายหลัง (w)
* เปิดวิดีโอในเบราว์เซอร์ (b)

* คัดลอกชื่อ (t)
* คัดลอก URL วิดีโอ (u)
* คัดลอกชื่อช่อง (c)
* คัดลอก URL ช่อง (h)
* คัดลอกข้อมูลสรุป (s)

### ฟีดช่องที่ติดตาม

หน้าต่างนี้แสดงวิดีโอจากช่องที่คุณติดตามภายในส่วนเสริม ซึ่งแยกจากการติดตามในบัญชี YouTube ไม่ต้องเชื่อมบัญชีหรือให้ข้อมูลส่วนตัว

มุมมองนี้ใช้แท็บมาตรฐานที่แบ่งตามประเภทเนื้อหา ต่างจากหน้าต่างรายการโปรด:

* **All (ทั้งหมด):** รวมเนื้อหาทุกประเภท
* **Video (วิดีโอ):** เฉพาะวิดีโอทั่วไป
* **Shorts:** เฉพาะวิดีโอสั้น
* **Live (ถ่ายทอดสด):** การถ่ายทอดสดและวิดีโอถ่ายทอดสดย้อนหลัง

นอกเหนือจากหมวดหมู่เริ่มต้นเหล่านี้ คุณสามารถสร้างหมวดหมู่เองและกำหนดว่าช่องใดจะปรากฏในแต่ละหมวดหมู่

#### คำสั่งในฟีดช่องที่ติดตาม

* กด Control+1 ถึง Control+0 เพื่อไปยังแท็บหมวดหมู่ รองรับสูงสุด 10 หมวดหมู่
* กด Control+ลูกศรขึ้น/ลง เพื่อเปลี่ยนลำดับหมวดหมู่ เช่นเดียวกับหน้าต่างรายการโปรด
* กด F2 เพื่อเปลี่ยนชื่อหมวดหมู่ ยกเว้นหมวดหมู่เริ่มต้นทั้ง 4
* กด Control+= เพื่อเพิ่มหมวดหมู่ใหม่
* กด Control+- เพื่อลบหมวดหมู่ ยกเว้นหมวดหมู่เริ่มต้นทั้ง 4
* ใช้ปุ่ม Action และ Copy ของแต่ละวิดีโอ หรือกด Enter เพื่อเปิดในเบราว์เซอร์
* กด Delete หรือ Alt+S เพื่อทำเครื่องหมายว่าวิดีโอดูแล้ว วิดีโอจะถูกนำออกจากรายการ
* กด Control+Delete เพื่อทำเครื่องหมายว่าวิดีโอทั้งหมดในแท็บปัจจุบันดูแล้ว

ปุ่มเพิ่มเติมในหน้าต่างนี้:

* **Mark as seen (ทำเครื่องหมายว่าดูแล้ว) (Alt+S)** — นำวิดีโอออกจากรายการ ใช้ปุ่ม Delete ได้เช่นกัน
* **Add new Subscription from clipboard URL (ติดตามช่องใหม่จาก URL ในคลิปบอร์ด) (Alt+N)** — ติดตามช่องโดยใช้ URL ที่คัดลอกไว้
* **Update Feed (อัปเดตฟีด) (Alt+U)** — เริ่มอัปเดตทุกช่องที่ติดตามด้วยตนเอง ตามค่าเริ่มต้น ส่วนเสริมจะอัปเดตอัตโนมัติเมื่อเริ่ม NVDA ด้วย
* **More... (เพิ่มเติม...) (Alt+M)** — เปิดเมนูย่อยที่มีตัวเลือกเพิ่มเติม:
  * ทำเครื่องหมายว่าทั้งหมดในแท็บปัจจุบันดูแล้ว (Ctrl+Delete) (a)
  * แสดงวิดีโอทั้งหมด รวมที่ดูแล้ว (v) — สลับระหว่างแสดงเฉพาะที่ยังไม่ดูและแสดงทั้งหมด การตั้งค่านี้บันทึกโดยอัตโนมัติ
  * จัดการช่องที่ติดตาม... (m)
  * เพิ่มหมวดหมู่ใหม่... Ctrl+= (c)
  * เปลี่ยนชื่อหมวดหมู่ปัจจุบัน... F2 (r)
  * ลบหมวดหมู่ปัจจุบัน... Ctrl+-
  * ล้างวิดีโอทั้งหมดในฟีด... — ลบวิดีโอทั้งหมดจากฐานข้อมูลโดยไม่ลบช่องที่ติดตาม เหมาะเมื่อฐานข้อมูลมีขนาดใหญ่จนกระทบประสิทธิภาพ NVDA

### จัดการช่องที่ติดตาม

หน้าต่างนี้แสดงช่องทั้งหมดที่คุณติดตาม ส่วนแรกเป็นรายการช่อง ตามด้วยตัวเลือกจัดการแต่ละช่อง:

* **Filter by Category (กรองตามหมวดหมู่)** — กรองรายการช่องตามหมวดหมู่ ค่าเริ่มต้นคือ “All (ทั้งหมด)”
* **Assign to Categories (กำหนดหมวดหมู่)** — เลือกหมวดหมู่ที่เนื้อหาจากช่องนี้จะปรากฏ
* **Content Types to Fetch (ประเภทเนื้อหาที่จะดึงข้อมูล)** — เลือกประเภทเนื้อหาที่ต้องการอัปเดตสำหรับช่องนี้ ได้แก่ วิดีโอ Shorts และถ่ายทอดสด มีประโยชน์สำหรับช่องที่เผยแพร่เนื้อหาเพียงบางประเภท
* **View Content... (ดูเนื้อหา...) (Alt+C)** — เรียกดูเนื้อหาของช่อง เช่นเดียวกับปุ่ม Action
* **Add new subscribe channel from Clipboard... (ติดตามช่องใหม่จากคลิปบอร์ด...) (Alt+N)** — ติดตามช่องใหม่โดยใช้ URL ในคลิปบอร์ด
* **Unsubscribe from this Channel (เลิกติดตามช่องนี้) (Alt+U)** — นำช่องออกจากรายการช่องที่ติดตาม
* **Save Changes (บันทึกการเปลี่ยนแปลง)** — **สำคัญ:** ต้องกดปุ่มนี้ก่อนปิดหน้าต่าง มิฉะนั้นการเปลี่ยนแปลงจะไม่ถูกบันทึก

### ตัวจัดการโปรไฟล์ผู้ใช้

หน้าต่างนี้ใช้จัดการโปรไฟล์ผู้ใช้ ส่วนเสริมมีโปรไฟล์ “default” มาให้ คุณสามารถเพิ่ม ลบ หรือเปลี่ยนชื่อโปรไฟล์ได้ที่นี่ หากต้องการสลับโปรไฟล์ ให้ไปที่แผงการตั้งค่าของส่วนเสริม

ในหน้าต่างนี้:

* กด F2 เพื่อเปลี่ยนชื่อโปรไฟล์ที่เลือก
* กด Delete เพื่อลบโปรไฟล์ที่เลือก

**หมายเหตุ:** การลบโปรไฟล์จะลบข้อมูลทั้งหมดที่เกี่ยวข้องอย่างถาวร วิดีโอ ช่อง และรายการติดตามที่บันทึกไว้ในโปรไฟล์นั้นจะสูญหาย

### l: (แสดงความคิดเห็น)

ความเห็นบนวิดีโอ YouTube มีสามประเภท:

* **Comment (ความคิดเห็น)** — ความคิดเห็นทั่วไปของผู้ชมในวิดีโอปกติ
* **Live chat (แชทสด)** — ข้อความที่ส่งระหว่างการถ่ายทอดสด
* **Live chat replay (แชทสดย้อนหลัง)** — แชทที่บันทึกไว้จากวิดีโอซึ่งเคยถ่ายทอดสด หากเจ้าของช่องไม่ได้ลบออก

YoutubePlus รองรับทั้งสามประเภทผ่านคำสั่งนี้

#### แชทสดของ...

สำหรับวิดีโอที่กำลังถ่ายทอดสด กด L แล้วส่วนเสริมจะเปิดหน้าต่างใหม่แสดงข้อความแชทที่เข้ามา โดยแสดงเฉพาะข้อความที่ได้รับหลังจากเรียกใช้คำสั่ง ข้อความก่อนหน้านั้นจะไม่ถูกรวบรวม

คุณสามารถปิดหน้าต่างนี้แล้วเปิดอีกครั้งด้วยคำสั่ง V ในชั้นคำสั่ง YoutubePlus ได้ ตราบใดที่การถ่ายทอดสดยังดำเนินอยู่และยังไม่ได้เริ่ม NVDA ใหม่

การกด L อีกครั้งบนการถ่ายทอดสดที่กำลังติดตามแชทอยู่จะไม่เริ่มใหม่ เพียงเปิดหน้าต่างแชทสดอีกครั้ง หรือยกหน้าต่างขึ้นมาด้านหน้าหากเปิดอยู่แล้ว หากกด L บนการถ่ายทอดสดอื่นขณะติดตามแชทอยู่ ส่วนเสริมจะขอให้ยืนยันการสลับ จากนั้นถามว่าจะบันทึกแชทที่รวบรวมมาแล้วก่อนแทนที่หรือไม่

ใช้คำสั่ง R เพื่อเปิดหรือปิดการให้ NVDA อ่านข้อความใหม่ทันทีที่เข้ามา เหมาะกับการถ่ายทอดสดที่มีข้อความไม่บ่อย สำหรับการถ่ายทอดสดที่มีข้อความจำนวนมาก อาจสะดวกกว่าหากปิดการอ่านอัตโนมัติและเลื่อนอ่านข้อความเองในหน้าต่าง

กด Shift+L เพื่อหยุดติดตามแชทของวิดีโอปัจจุบัน

มีการตั้งค่าห้ารายการที่ส่งผลโดยตรงต่อฟีเจอร์นี้:

* **Automatically speak incoming live chat (อ่านแชทสดที่เข้ามาโดยอัตโนมัติ):** เมื่อเลือก NVDA จะอ่านข้อความใหม่ทันที ทำงานเหมือนคำสั่ง R แต่บันทึกไว้เป็นค่าเริ่มต้น
* **Voice profile (โปรไฟล์เสียง):** อ่านแชทสดที่เข้ามาด้วยการตั้งค่าเสียงจากโปรไฟล์การกำหนดค่าของ NVDA เช่น ใช้ตัวสังเคราะห์เสียงคนละตัว ใช้ได้เมื่อเปิดการอ่านอัตโนมัติเท่านั้น ดูรายละเอียดด้านล่าง
* **Alert sounds for live chat (เสียงแจ้งเตือนแชทสด):** เล่นเสียงเมื่อมี Super Chat, Super Sticker หรือสมาชิกใหม่ ทำงานได้ทั้งเมื่อเปิดและปิดการอ่านอัตโนมัติ ดูรายละเอียดด้านล่าง
* **Live chat refresh interval (ช่วงเวลารีเฟรชแชทสด):** ความถี่ในการตรวจหาข้อความใหม่ หน่วยเป็นวินาที ค่าเริ่มต้นคือ 5 วินาที
* **Message history limit (ขีดจำกัดประวัติข้อความ):** จำนวนข้อความสูงสุดที่เก็บในหน่วยความจำระหว่างการใช้งานหนึ่งครั้ง หน้าต่างแชทสดจะแสดงเฉพาะข้อความล่าสุดไม่เกินจำนวนนี้ ค่าเริ่มต้นคือ 5,000 ข้อความ ส่วนเสริมยังเก็บข้อความทั้งหมดเบื้องหลังเพื่อส่งออก สูงสุด 200,000 ข้อความ เพื่อป้องกันการใช้หน่วยความจำมากเกินไป

เมื่อการถ่ายทอดสดจบลง หรือส่วนเสริมตรวจพบว่าจบแล้ว จะมีกล่องโต้ตอบถามโดยอัตโนมัติว่าต้องการส่งออกข้อความที่รวบรวมไว้ทั้งหมดหรือไม่ กด Yes (ใช่) เพื่อบันทึกประวัติแชทเป็นไฟล์

##### โปรไฟล์เสียง

การตั้งค่า Voice profile ช่วยให้อ่านแชทสดด้วยเสียงที่ต่างจากเสียงที่ NVDA ใช้อ่านส่วนอื่น เช่น ใช้ตัวสังเคราะห์เสียงอื่นอย่าง SAPI 5 วิธีใช้คือสร้างโปรไฟล์ใน NVDA ที่ `NVDA menu -> Configuration profiles...` (เมนู NVDA -> โปรไฟล์การกำหนดค่า...) โดยกำหนดตัวสังเคราะห์เสียงและการตั้งค่าเสียงที่ต้องการสำหรับแชท จากนั้นเลือกโปรไฟล์นั้นในการตั้งค่า YoutubePlus โปรไฟล์นี้ใช้เป็นแหล่งข้อมูลการตั้งค่าเสียงเท่านั้น จะไม่ถูกเปิดใช้งานจริง และข้อความอื่นของ NVDA ยังคงใช้เสียงปกติ เลือก “(None, keep the current voice)” หรือ “(ไม่มี ใช้เสียงปัจจุบันต่อไป)” เพื่อปิดฟังก์ชันนี้

แชทจะอ่านด้วยตัวสังเคราะห์เสียงแยกต่างหากที่ทำงานควบคู่กับ NVDA คล้ายสื่อที่เล่นอยู่เบื้องหลัง การกดปุ่ม การเคลื่อนที่ หรือเสียงพูดใด ๆ ของ NVDA จะไม่พัก ขัดจังหวะ หรือยกเลิกเสียงนี้ ทั้งสองเสียงจึงดังพร้อมกันได้ ควรเลือกเสียงแชทที่แตกต่างอย่างชัดเจน กด R ในชั้นคำสั่ง YoutubePlus เพื่อหยุดเสียงแชททันที

ข้อความจะถูกอ่านต่อกันทีละข้อความ หากแชทเข้ามาเร็วกว่าที่อ่านทัน จะอ่านเฉพาะข้อความธรรมดาที่รออยู่ล่าสุด 20 ข้อความ แต่ทุกข้อความยังคงปรากฏในหน้าต่างแชทสดและไฟล์ส่งออก ส่วน Super Chat, Super Sticker และสมาชิกใหม่จะได้รับการอ่านก่อนข้อความธรรมดา และยังคงอยู่แม้ข้อความอื่นถูกข้าม หากโหมดเสียงพูดของ NVDA เป็นปิดเสียง เสียงบี๊บ หรือพูดเมื่อสั่ง แชทจะไม่ถูกอ่านออกเสียง แต่ยังแสดงในหน้าต่างแชทสดและบนจอแสดงผลอักษรเบรลล์

##### เสียงแจ้งเตือน

เหตุการณ์ Super Chat, Super Sticker และ New member (สมาชิกใหม่ที่เข้าร่วมช่อง) สามารถเล่นเสียงแยกกันเมื่อเข้ามา คุณเลือกได้ในการตั้งค่าว่าจะให้เหตุการณ์ใดมีเสียง ไฟล์เสียงคือ `superchat.wav`, `supersticker.wav` และ `membership.wav` ในโฟลเดอร์ `sounds` ของส่วนเสริม หากไม่มีไฟล์ จะใช้เสียงบี๊บแทน เสียงแจ้งเตือนทำงานได้ไม่ว่าจะเปิดการอ่านอัตโนมัติหรือไม่ จึงรับรู้เหตุการณ์เหล่านี้ได้โดยไม่ต้องฟังทุกข้อความ เมื่อมีหลายเหตุการณ์ประเภทเดียวกันเข้ามาพร้อมกัน เสียงจะเล่นเพียงครั้งเดียว

เหตุการณ์เหล่านี้แสดงในหน้าต่างแชทสดเช่นเดียวกับข้อความอื่น โดยมีป้ายกำกับ *Super Chat*, *Super Sticker* หรือ *New member* และรวมอยู่ในไฟล์ส่งออกแชทด้วย

##### ปัญหาที่ทราบ

* โปรไฟล์เสียงจะเริ่มตัวสังเคราะห์เสียงตัวที่สองควบคู่กับตัวของ NVDA หากเริ่มไม่ได้ จะมีข้อความแจ้งและใช้เสียงปัจจุบันอ่านแชทแทน ตัวสังเคราะห์เสียงบางตัวอาจไม่รองรับการทำงานสองอินสแตนซ์พร้อมกัน
* ไม่แนะนำให้ใช้ไดรเวอร์ตัวสังเคราะห์เสียงเดียวกันทั้งกับ NVDA และเสียงแชท เช่น ใช้ Vocalizer ทั้งคู่ ไดรเวอร์บางตัวใช้เอนจินร่วมกันระหว่างอินสแตนซ์ เมื่อแชทเข้ามาเร็วมาก เสียงทั้งสองอาจรบกวนกัน เช่น เสียงแชทเงียบลง หรือเสียง NVDA ได้รับผลกระทบ ส่วนเสริมจะพยายามเริ่มเสียงแชทใหม่เอง หากยังเงียบ ให้กด R สองครั้งเพื่อปิดแล้วเปิดใหม่ หากเสียง NVDA ได้รับผลกระทบ ให้เริ่ม NVDA ใหม่ การเลือกตัวสังเคราะห์เสียงอื่นสำหรับโปรไฟล์แชทช่วยหลีกเลี่ยงปัญหานี้ได้
* ยังไม่ได้ทดสอบอย่างละเอียดกับการถ่ายทอดสดที่มีแชทเข้ามาเร็วมาก หาก NVDA ไม่ตอบสนอง ให้ปิดโปรไฟล์เสียง หรือปิดการอ่านอัตโนมัติแล้วอ่านข้อความในหน้าต่างแชทสดแทน

#### ความคิดเห็น / แชทสดย้อนหลัง

สำหรับวิดีโออัปโหลดทั่วไปหรือวิดีโอถ่ายทอดสดที่เก็บไว้ คุณสามารถเข้าถึงความคิดเห็นได้ด้วยวิธีเดียวกัน หากมีทั้งแชทสดย้อนหลังและความคิดเห็นทั่วไป จะมีกล่องโต้ตอบถามว่าต้องการโหลดแบบใด

ไม่มีการจำกัดจำนวนความคิดเห็นที่แสดง แต่การโหลดอาจใช้เวลาสำหรับวิดีโอที่มีความคิดเห็นมาก

ความคิดเห็นที่ปักหมุดจะแสดงก่อน ตามด้วยความคิดเห็นอื่นตามลำดับที่กำหนดในการตั้งค่า คือใหม่ที่สุดก่อนหรือเก่าที่สุดก่อน

#### ส่วนต่าง ๆ ของหน้าต่างความคิดเห็น

* **ช่องค้นหา** — พิมพ์เพื่อกรองความคิดเห็น ผลลัพธ์เปลี่ยนทันที
* **กล่องคำสั่งผสมสำหรับตัวกรอง** — เลือกตัวกรอง แล้วส่วนเสริมจะกรอกช่องค้นหาให้อัตโนมัติ:
  * No Filter (ไม่กรอง) — ค่าเริ่มต้น แสดงความคิดเห็นทั้งหมด
  * Filter by Selected Author (กรองตามผู้เขียนที่เลือก) — แสดงเฉพาะความคิดเห็นของผู้แสดงความคิดเห็นที่เลือก
  * Show Super Chats Only (แสดงเฉพาะ Super Chat)
  * Show Super Stickers Only (แสดงเฉพาะ Super Sticker)
  * Show Super Thanks Only (แสดงเฉพาะ Super Thanks)
* **รายการความคิดเห็น** — แสดงชื่อผู้แสดงความคิดเห็น ตามด้วยข้อความ
* **พื้นที่ข้อความแบบอ่านอย่างเดียว** — เลื่อนอ่านข้อความเต็มของความคิดเห็นที่เลือก เหมาะเมื่อข้อความยาวจนแสดงในรายการได้ไม่ครบ
* **ปุ่ม Copy (คัดลอก) (Alt+C หรือ Ctrl+C)** — คัดลอกความคิดเห็นที่เลือก
* **ปุ่ม Export (ส่งออก) (Alt+E)** — บันทึกความคิดเห็นทั้งหมดเป็นไฟล์ข้อความในโฟลเดอร์ที่กำหนดในการตั้งค่า
* **ช่องยอดเงินที่ชำระทั้งหมด** — แสดงเฉพาะแชทสดย้อนหลัง โดยแสดงยอดบริจาครวมจากผู้ชมระหว่างการถ่ายทอดสด

## การตั้งค่า

เปิดการตั้งค่าที่ `NVDA -> Preferences -> Settings...` (NVDA -> การตั้งค่า -> ตั้งค่า...) แล้วเลือกหมวด **“YoutubePlus”**

* **Active Profile (โปรไฟล์ที่ใช้งาน):** เลือกโปรไฟล์ที่ต้องการใช้ ต้องเริ่มโปรแกรมใหม่หลังสลับโปรไฟล์
* **Manage Profile (จัดการโปรไฟล์):** เปิดหน้าต่างตัวจัดการโปรไฟล์ผู้ใช้
* **Quick Action (Space bar) (การดำเนินการด่วนด้วยปุ่ม Space):** เลือกว่าจะให้ปุ่ม Space ทำอะไรในหน้าต่างรายการวิดีโอ โดยมีตัวเลือกทั้งหมดจากเมนู Action
* **Notification mode (โหมดแจ้งเตือน):** เลือกวิธีแจ้งสถานะการทำงานเบื้องหลัง:
  * *Beep (บี๊บ):* เสียงบี๊บสั้น ๆ
  * *Sound (เสียง):* เสียงเอฟเฟกต์
  * *Silent (เงียบ):* ไม่มีเสียงแจ้งเตือน แต่ยังมีเสียงพูดตอบกลับ
* **Default sort order (ลำดับการเรียงเริ่มต้น):** เลือกให้รายการ เช่น ความคิดเห็นและวิดีโอของช่อง เรียงแบบ **Newest First (ใหม่ที่สุดก่อน)** หรือ **Oldest First (เก่าที่สุดก่อน)**
* **Items to fetch (จำนวนรายการที่จะดึงข้อมูล):** จำนวนรายการต่อประเภทเนื้อหาเมื่อเรียกดูช่องและอัปเดตฟีดช่องที่ติดตาม ค่าเริ่มต้นคือ 20
* **Default content types (ประเภทเนื้อหาเริ่มต้น):** เลือกประเภทเนื้อหาที่จะดึงข้อมูลสำหรับช่องที่ติดตามใหม่ ได้แก่ วิดีโอ Shorts และ/หรือถ่ายทอดสด
* **Background update interval (ช่วงเวลาอัปเดตเบื้องหลัง):** ความถี่ในการตรวจหาเนื้อหาใหม่จากช่องที่ติดตาม ปิดได้ หรือตั้งค่าตั้งแต่ 15 นาทีถึง 24 ชั่วโมง ตามค่าเริ่มต้น ส่วนเสริมยังอัปเดตอัตโนมัติทุกครั้งที่เริ่ม NVDA
* **Automatically speak incoming live chat (อ่านแชทสดที่เข้ามาโดยอัตโนมัติ):** เมื่อเลือก NVDA จะอ่านข้อความแชทใหม่ทันทีที่เข้ามา
* **Voice profile (โปรไฟล์เสียง):** เลือกโปรไฟล์การกำหนดค่าของ NVDA เพื่ออ่านข้อความแชทสดที่เข้ามา เฉพาะแชทสดเท่านั้นที่ใช้การตั้งค่าเสียงจากโปรไฟล์นั้น ได้แก่ ตัวสังเคราะห์เสียง เสียงพูด อัตราเร็ว ระดับเสียงสูงต่ำ และความดัง ส่วนอื่นของ NVDA ยังใช้เสียงปกติ และโปรไฟล์จะไม่ถูกเปิดใช้กับทั้งระบบ แชทอ่านด้วยตัวสังเคราะห์เสียงแยกต่างหาก จึงใช้คนละตัวกับ NVDA ได้ และการกดปุ่มหรือเสียงพูดของ NVDA จะไม่ขัดจังหวะแชท เลือก “(None, keep the current voice)” หรือ “(ไม่มี ใช้เสียงปัจจุบันต่อไป)” เพื่อปิดฟังก์ชันนี้ ใช้ได้เมื่อเปิดการอ่านอัตโนมัติเท่านั้น
* **Alert sounds for live chat (เสียงแจ้งเตือนแชทสด):** เลือกเหตุการณ์ที่จะเล่นเสียงเมื่อเข้ามา ได้แก่ Super Chat, Super Sticker และสมาชิกใหม่ ทำงานได้ไม่ว่าจะเปิดการอ่านอัตโนมัติหรือไม่
* **Live chat refresh interval (ช่วงเวลารีเฟรชแชทสด):** ความถี่ในการตรวจหาข้อความใหม่ หน่วยเป็นวินาที ค่าเริ่มต้นคือ 5 วินาที
* **Message history limit (ขีดจำกัดประวัติข้อความ):** จำนวนข้อความแชทสูงสุดที่เก็บในหน่วยความจำระหว่างการใช้งานหนึ่งครั้ง
* **Default subtitle format (รูปแบบคำบรรยายเริ่มต้น):** รูปแบบไฟล์คำบรรยายสำหรับการดาวน์โหลด ได้แก่ SRT, VTT, TTML หรือ TXT ซึ่งเป็นข้อความธรรมดาที่ไม่มีรหัสเวลา
* **Download Quality and Format Options (ตัวเลือกคุณภาพและรูปแบบการดาวน์โหลด) (Alt+D):** ส่วนที่ยุบและขยายได้ โดยเริ่มต้นจะยุบอยู่ กด Alt+D จากที่ใดก็ได้ในหน้าการตั้งค่า หรือสั่งงานส่วนนี้โดยตรง เพื่อขยายหรือยุบ ภายในมี:
  * *Preferred video quality (คุณภาพวิดีโอที่ต้องการ):* ดีที่สุดที่มี หรือจำกัดความละเอียดตั้งแต่ 2160p ลงมาถึง 360p
  * *Preferred video container (รูปแบบคอนเทนเนอร์วิดีโอที่ต้องการ):* MP4, MKV หรือ WebM
  * *Preferred audio quality (when converting) (คุณภาพเสียงที่ต้องการเมื่อแปลงรูปแบบ):* ดีที่สุดที่มี หรืออัตราบิตตั้งแต่ 320 ลงมาถึง 96 kbps ใช้เฉพาะเมื่อรูปแบบเสียงด้านล่างไม่ได้เป็น “Best available”
  * *Preferred audio format (รูปแบบเสียงที่ต้องการ):* ดีที่สุดที่มีและไม่แปลงรูปแบบ ซึ่งเป็นค่าเริ่มต้น โดยดาวน์โหลดรูปแบบที่ YouTube ให้มาโดยไม่ต้องใช้ FFmpeg หรือเลือกแปลงเป็น MP3, WAV, M4A/AAC, FLAC, Opus หรือ Vorbis (OGG) การแปลงทุกรูปแบบต้องใช้ FFmpeg เช่นเดียวกับการดาวน์โหลดวิดีโอ
* **Cookie method (Experimental) (วิธีใช้คุกกี้ — ทดลอง):** เลือกเบราว์เซอร์ที่คุณลงชื่อเข้าใช้ YouTube ส่วนเสริมจะดึงคุกกี้จากเบราว์เซอร์นั้นเพื่อยืนยันตัวตนในการส่งคำขอ ซึ่งอาจช่วยแก้ข้อผิดพลาด “Sign in to confirm you're not a bot” หรือ “ลงชื่อเข้าใช้เพื่อยืนยันว่าคุณไม่ใช่บอต” โปรดทราบว่าฟีเจอร์นี้ยังอยู่ในขั้นทดลอง ผลลัพธ์แตกต่างกันตามเบราว์เซอร์และการกำหนดค่าระบบ
* **Default download and export folder path (เส้นทางโฟลเดอร์ดาวน์โหลดและส่งออกเริ่มต้น):** โฟลเดอร์ปลายทางสำหรับวิดีโอ/เสียงที่ดาวน์โหลดและแชทที่ส่งออก
* **Backup data now (สำรองข้อมูลตอนนี้):** สำรองข้อมูลทั้งหมดของโปรไฟล์ที่ใช้งานด้วยตนเอง ส่วนเสริมยังสำรองข้อมูลอัตโนมัติทุกวันเบื้องหลังด้วย
* **Restore data from backup (กู้คืนข้อมูลจากข้อมูลสำรอง):** แสดงรายการข้อมูลสำรองที่มี ย้อนหลังได้สูงสุด 5 วัน เพื่อให้เลือกวันที่ต้องการกู้คืน

## ข้อมูลเพิ่มเติม

ส่วนเสริมนี้ใช้ไลบรารีหลักสองตัว ได้แก่ [pytchat](https://pypi.org/project/pytchat/) สำหรับติดตามแชทสด และ [yt-dlp](https://pypi.org/project/yt-dlp/) สำหรับเข้าถึงข้อมูล YouTube อื่นทั้งหมด ขอขอบคุณผู้พัฒนาไลบรารีทั้งสองอย่างจริงใจ

### เกี่ยวกับ yt-dlp

[yt-dlp](https://github.com/yt-dlp/yt-dlp) เป็นหนึ่งในเครื่องมือโอเพนซอร์สที่มีความสามารถสูงที่สุดสำหรับดาวน์โหลดวิดีโอและเสียงจากเว็บไซต์ทั่วโลก รองรับมากกว่า 1,000 เว็บไซต์ ไม่ใช่เฉพาะ YouTube ใช้งานได้ฟรี เปิดเผยซอร์สโค้ด และมีชุมชนทั่วโลกดูแลอย่างต่อเนื่อง ไม่มีโฆษณาหรือมัลแวร์ ต่างจากเครื่องมือดาวน์โหลดผ่านเว็บหลายตัว

อย่างไรก็ตาม โปรดคำนึงถึงแนวทางการใช้งานต่อไปนี้:

1. **การใช้งานอย่างเหมาะสม:** หลีกเลี่ยงการดึงข้อมูลจำนวนมากหรือส่งคำขอซ้ำ ๆ ในช่วงเวลาสั้น ๆ YouTube อาจตรวจพบกิจกรรมผิดปกติและจำกัดการเข้าถึงจากที่อยู่ IP ของคุณชั่วคราว
2. **ลิขสิทธิ์และความเป็นส่วนตัว:** ข้อมูลหรือเนื้อหาที่ดึงมาควรใช้เพื่อการรับชมหรือวิเคราะห์ส่วนบุคคลเท่านั้น โปรดเคารพข้อกำหนดการให้บริการของแต่ละแพลตฟอร์ม และไม่ใช้ข้อมูลในลักษณะที่ละเมิดลิขสิทธิ์
3. **ความรับผิดชอบ:** คุณเป็นผู้รับผิดชอบต่อวิธีใช้ซอฟต์แวร์นี้ ผู้พัฒนาส่วนเสริมจัดเตรียมเพียงส่วนติดต่อสำหรับเข้าถึงข้อมูล YouTube ผ่านไลบรารี yt-dlp

**เคล็ดลับ:** หากต้องประมวลผลข้อมูลจำนวนมาก ให้เว้นระยะระหว่างคำขอ เพื่อรักษาความเสถียรของการเชื่อมต่อและหลีกเลี่ยงการถูกจำกัดการเข้าถึง
